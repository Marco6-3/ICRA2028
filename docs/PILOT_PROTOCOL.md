# D1 / D2 首轮验证协议（草案）

日期：2026-09-16。目的：用尽可能少的工作判断“接触时间信息是否重要、策略是否使用真实触觉”。本文件是实验设计，没有运行记录。确认测量与可区分现象后再扩展方法。

## 1. 先确定一个现象

选择一次能稳定出现接触建立、滑移趋势或接触纠正的短操作。任务必须符合当前机器人的可执行命令；若只有位置/开合控制且反应慢，不把高速救回滑落设成强制目标。

候选例子：抓起物体后按固定路径搬运，在初始条件中改变负载或表面；或在可重复夹具中完成接触修正。优先选择能通过独立相机/标记判定物体变化的设置，不同时引入多个新工具和控制器。

预先写出：成功、失效、超时、事件发生的判定；能够观察到的最小变化；超出设备能力的条件。物体外观、轨迹阶段和物理难度尽量可分别操纵。

## 2. 核验数据与执行链

| 必记字段 | 用途 |
| --- | --- |
| 原始传感器时间戳、主机接收时间、时钟域 | 分离真实采样与传输抖动；设备时钟不同先估偏移与漂移 |
| 原始触觉信号、传感器ID、安装与零点记录 | 判断重装、漂移、磁干扰和采集批次差异 |
| 图像曝光/采集时刻、帧到达时刻 | 对齐事件，区分图像延迟 |
| 机器人状态、命令内容、发送和执行可观测时刻 | 分离策略和执行滞后；无执行时间戳时给估计范围 |
| 决策时刻、输入截止时刻、输出时刻 | 防止用到未来数据并测推理延迟 |
| episode、物体实例、批次、初始条件ID | 保证划分与独立统计单位 |
| 事件标注、成功/失败、异常与视频索引 | 可复查，不仅保留成功演示 |

AnySkin磁场变化不是标定力。先检查无接触时关节动作是否引起信号变化；若引起，可能把机器人运动或磁干扰误认为接触。无独立力传感器/标定时，不报告牛顿力峰值。

先测采样率、到达间隔、丢包、推理P50/P95和命令执行能力，所有频率均用当前设备测量值。延迟误差若已经接近想研究的事件时间尺度，应先解决测量问题。

## 3. 分清两种实验问题

**训练可用性：** 每个输入条件独立训练，使用同一原始演示池、划分、视觉骨干、动作空间、训练预算和模型选择规则。它回答“这种信息表示能够学到什么”。

**现有策略依赖：** 冻结同一模型，再移时/替换输入，回答“该策略对这种输入变化有多敏感”。人工干预可能超出训练分布，必须与物理干预及重新训练消融互相印证。两种结果分开报告。

## 4. 最小对照集合

先做B0、B1、B3；确认触觉历史值得研究后再补B2、B4及机制对照，不要求第一周把全部训练跑完。

| 条件 | 可用触觉信息 | 要区分什么 |
| --- | --- | --- |
| B0 | 不使用触觉；视觉与本体状态保持一致 | 触觉是否有增量 |
| B1 | 当前以前最新已到达值 | 瞬时信号是否已经足够 |
| B2 | 历史经因果滤波和均匀降采样 | 标准处理可保留多少有效信息 |
| B3 | 原始历史输入 | 完整信息参考；不自动称同计算成本 |
| B4 | 因果事件摘要/事件附近历史 | 在受限输入量下保留时机是否有效 |
| C1 | 实际相同触觉，额外加入已知延迟 | 信息新鲜度的作用 |
| C2 | 阶段/时间代理，替代真实触觉 | 任务进度线索能解释多少收益 |
| C3 | 同阶段匹配替换或过去窗口乱序 | 特定接触信息/时间顺序的作用，仅作有效性受限的诊断 |

B4的事件检测必须只用当前以前已收到的数据；阈值或检测器在训练/验证集确定，不能从整条轨迹未来峰值倒推在线接触起点。专家标签是分析真值，不免费提供给部署方法。

C2的可部署阶段代理只能从已到达的本体历史、时间等共同输入估计；人工阶段真值单独标为诊断上界，不能与真实在线方法混成一个主比较。进入方法比较时还应加入相同输入下的简单阈值/滤波反馈或可行的解析控制基线。若研究训练优化，再比较普通模态dropout与GAP类方法；若研究触觉内容，再考虑PredTac类当前触觉预测基线，保留其额外监督成本。

C3需记录乱序方式：仅重排token而保留每个值的真实时间戳，模型可能恢复原顺序；只把值放到别的时间戳，则同时改变触觉与姿态的对应关系。分别报告这些诊断，不能将二者都称为只改变时间顺序。按整条轨迹最终长度归一化的进度也属于未来信息，不能提供给在线阶段代理。

本协议的D1首先改变输入表示，固定动作执行和策略决策频率。相关工作页提及的事件触发动作更新是另一项可选问题，需要另立协议并固定平均更新预算，不能混入这里的主因果对照。

只保留事件点可能丢失稳定接触幅值，应比较事件摘要是否需要保留最近状态/基础采样；这是待验证设计，不预设压缩一定胜出。

## 5. 时间和计算公平性

1. 所有方法使用相同输出控制率、执行器接口和动作平滑设置。不能把输入改进和更快执行同时变化。
2. B1/B2/B3使用明确的共同历史跨度和输入截止时间。滤波只能因果实现，记录群延迟；禁止使用未来插值或居中窗口。
3. 为区分滤波延迟与信息丢失，增加延迟匹配的完整历史参考。移时只用过去信号；提前看到未来只能作为明确标注的离线上界。
4. 分开报告“完整输入参考”和“相同输入token/推理预算”的比较。相同参数量不保证相同算力，相同token数不保证相同延迟。
5. 预算比较同时报告任务表现、输入样本/字节、实测推理时间与内存；在相同硬件模式测量。
6. 时间偏移、信号噪声、采样率各自改变，不一次同时改变多个因素。幅值统计匹配不等于时序结构匹配。

## 6. 干预如何支持解释

主干预使用可重复的真实接触条件变化，如可控负载或表面条件；方法在相同初始条件编号下配对评测、随机化顺序，以减轻热漂移与学习顺序影响。

若在相同视觉/阶段附近改变物理状态，正确触觉能改善对应纠正；而同阶段错误触觉破坏该纠正，才逐渐支持在线接触信息的作用。还需排除执行器饱和、传感器故障、外观变化与输入分布失真。

对仿真可以精确操纵隐藏状态；对真机通常只能近似匹配，报告剩余差异。仅做屏蔽/随机噪声后成功率下降，不能证明内部存在独立“触觉功能区”。

## 7. 划分、样本量与统计

先导可从约20–40条短轨迹、两个可重复条件起步，数量只是工时估计，不是足够统计功效的保证，也不是已采集记录。若这一规模不足以让基线运行，先判断是数据覆盖不足还是实现问题，不能直接否定假设。

训练/验证/测试按物体实例和采集批次划分；同一episode及其全部切窗只能在同一划分内。验证集用于选择阈值、时间窗口和模型；正式留出测试不反复调参。D3还需留出操作者，D4还需留出工具或动力学组合。

先导记录每次复位、有效采集、故障和训练成本。正式规模根据有实际意义的差异阈值、物体与批次变异、功效或精度分析和真实机时决定，不预先锁死大矩阵。

报告逐物体结果、配对差异及置信区间。重复帧不作为独立样本；同一物体多次trial与不同训练种子属于不同变异层级，分开表达。簇数量太少时不依赖不稳定的复杂模型给出强结论。候选方法进入正式比较后安排多个训练种子；先导单种子仅用于排错和筛选。

## 8. 判据和下一步

| 观察 | 当前可支持的判断 | 下一步 |
| --- | --- | --- |
| 原始历史相对最近值在接触阶段稳定有益，延迟匹配后仍在 | 时间历史可能包含额外有用信息 | 补事件摘要、降采样和真实扰动对照 |
| B1已覆盖主要收益，增加历史无可辨别增益 | 当前任务中瞬时触觉可能足够 | 估计差异范围；缩小D1或转D2 |
| 阶段代理能复现大部分收益，物理扰动下触觉策略失败 | 可能存在阶段捷径，仍需检查干预与接口 | 设计D2诊断和训练改进 |
| 只有不匹配延迟/算力时有提升 | 目前不能归因于事件信息 | 修公平对照，改变贡献表述 |
| 无法稳定标注事件或时间误差过大 | 测量不能回答问题 | 先修数据链路；限制10月底前的工程投入 |
| 实验有效且可排除有意义收益 | 此设置下有用的负结果 | 记录边界，不不断换条件直到“显著” |

正式选题前至少具备：可信测量、可复现现象、最近邻差异、闭环可行性。一个负先导不足以否定整个触觉方向，一个正先导也不足以确定IROS贡献。
