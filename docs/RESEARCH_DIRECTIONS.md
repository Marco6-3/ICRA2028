# 感兴趣的具身智能方向：从愿景到可验证问题

整理日期：2026-09-16。范围：围绕触觉、OM-1、人类交互数据、工具泛化、动作语义、可解释性与预测控制的定向检索。不是完整综述，所有研究缺口都需要进一步核查。

当前问题之间的联系是：交互数据保留了什么信息 → 表示如何使用这些信息 → 策略是否依赖它 → 能否在新物体或工具上执行。大方向可以长期保留，本届投稿只选择其中一个可区分的问题。

## D1：接触事件的时机，究竟值多少信息？

**A. 问题。** 相机、触觉和机器人状态频率不同。如果统一降采样，丢掉的究竟是无关冗余，还是决定抓取、稳定接触和纠正动作的关键时间结构？在固定动作频率与计算预算下，哪些信息必须保留？

**B. 已有工作与缺口。** RDP 已做慢快触觉控制；FA-RDP 已研究接触相关的频率调节；TacForcing 已做执行期间触觉更新。因此“更快触觉分支”不是研究缺口。候选缺口是：在相同控制链路下区分样本数量、信号幅值、事件顺序/相位、输入新鲜度的贡献，并证明一种预算受限的表示确实保留了有用信息。[相关工作](TACTILE_RELATED_WORK.md)

**C. 假设与竞争解释。** 关键事件附近的短时信息可能比全程等密度采样更有用。竞争解释包括：最新触觉值已经足够；收益主要来自低延迟；更高采样率只改善噪声平均；触觉只是报告任务阶段。上述解释可同时部分成立。

**D. 最小实验。** 一台机械臂、一套固定传感器、一个明确接触任务。按设备控制能力选择接触建立后搬运、接触修正或夹持稳定任务。保存原始时序，对比最近值、因果抗混叠降采样、完整历史、因果事件摘要。固定输出控制率，并分别做延迟匹配、同预算与完整输入参考对照。真实输入只能包含当前以前已收到的样本；详见 [协议](PILOT_PROTOCOL.md)。

**E. 评价。** 成功率及物体级不确定性、事件检出与时间误差、扰动至有效修正的端到端延迟、P95推理时间、输入量/计算量、未见负载或表面条件。事件标签应有独立观测支持。模拟磁场幅值不能替代力真值。

**F. 发表潜力与可行性。** 当前优先级最高，前提是10月能复现时间信息的重要性。可能贡献是信息需求的测量与边界，以及有闭环收益的事件保留方法。仅对一个任务移时后性能下降，或只在更多算力下涨点，证据不够。平日可处理日志，周末验证；不需要先开发完整采集手套。

## D2：模型用触觉感知接触，还是用它猜测进度？

**A. 问题。** 给 ACT/DP 加触觉不代表模型学会了接触。触觉可能与夹持动作、时间和示教阶段高度相关，模型可能依靠这些关联完成常规回放，却无法应对真正的物理变化。

**B. 已有工作与缺口。** GAP 已研究视觉—本体模态捷径与分阶段干预；AnySkin 已验证触觉策略和滑移检测；2026-09-14 的 PredTac 已做固定策略的触觉内容替换。候选缺口应具体到触觉的三种角色：在线物理状态、阶段提示、轨迹代理，并以真实物理干预及其导出的改进区分。不能把“发现多模态有捷径”或“替换触觉分析依赖”作为全新结论。[GAP、AnySkin及PredTac](TACTILE_RELATED_WORK.md)

**C. 假设。** 在固定阶段和接近相同姿态下改变负载/摩擦时，依赖真实接触的策略应作出相应调整；仅依赖阶段的策略未必能适应。竞争解释是触觉确实有效，但输入干预超出训练分布造成失效，或动作接口无法表达必要纠正。

**D. 最小实验。** 比较视觉+本体、加入最新触觉、加入触觉历史，以及用阶段/时间代理替代触觉的基线。在任务可匹配的范围内，分别改变物理接触、移时触觉、交换同阶段触觉。屏蔽和交换先作为离线诊断；用真实负载/表面干预与训练时模态消融交叉验证。

**E. 评价。** 观测—动作—结果是否形成符合物理预期的变化；常规与扰动条件下的收益差；分阶段失效；不同物体和采集批次的复现。权重热图、注意力图和线性probe作为辅助证据，不能单独定位功能。

**F. 潜力。** 可与D1共用数据，成为其机制诊断；也可在新颖性成立时单独研究感知依赖的评测或训练干预。优点是小模型即可做。风险是简单遮罩实验已经很多，必须有有效干预、泛化边界和修正后行为，不能把分布外破坏等同因果解释。

## D3：人类交互数据真正转移了什么？

**A. 问题。** 人类示教中的接触开始、负载变化、滑移趋势是否提供了能跨机器人接口迁移的信息？相对于视频或手部轨迹，新增触觉改善的是数据质量、状态理解，还是动作监督？

**B. 已有工作与缺口。** OM-1 公开了共同接口与分层控制，但未公开编码器和完整评测。MimicTouch、ForceMimic、TactAlign 已覆盖人类触觉/力数据与机器人学习，因此“加入人类触觉再对齐”不够。可研究同一采集条件下，哪些接触信息在少量机器人适配数据中仍有增量，何时因传感器或动作接口差异失效。[OM-1](OM1_EVIDENCE.md)、[TactAlign](TACTILE_RELATED_WORK.md)、[MimicTouch](https://sites.google.com/view/mimictouch/)、[ForceMimic](https://forcemimic.github.io/)

**C. 假设。** 与直接对齐原始信号相比，接触阶段和短期物体效果可能是较稳定的共享监督。竞争解释：收益来自更多演示、同一物体泄漏、相机差异被消除、人工标定更好或低层控制器更强。

**D. 最小实验。** 只选人类和现有机器人都能完成的一种操作，先用现成采集链路。保持下游策略、控制器和机器人适配数据相同，比较机器人数据、加入人类视觉/轨迹、再加入人类接触信号。增加相同采集时间的机器人额外数据基线；分别报告机器人样本预算与总采集时间预算。再比较原始信号对齐、事件监督与等容量无事件监督。

**E. 评价。** 按人、物体、采集批次划分，检查是否学到操作者或设备身份；报告固定机器人演示预算下的成功率、适配曲线和独立留出场景。若用了机器人标定、演示或微调，应如实写出，不能称整个系统零机器人数据。

**F. 潜力。** 最贴近OM-1数据来源问题，也可能契合正在进行的数据源合作。若9月底已有可复用同步数据与稳定机器人接口，可升为主线；若要从零造多模态手套、追踪系统和全新力控，时间风险很高。跨一个人类接口和一个机器人只能支持该范围，不能概括任意本体。

## D4：一次短探测能否让策略适应新工具？

**A. 问题。** 换工具后，机器人能否通过一个不包含完整目标任务的短探测，识别当前质量分布、柔顺性或接触效果，并在不更新策略权重时调整后续动作？

**B. 已有工作与缺口。** SwingBot 已用触觉探索推断物理特征并控制未见物体；ICRT 已做基于示教上下文的策略。问题应收窄为“非任务示范的探测历史是否比工具身份/几何和普通状态历史提供额外迁移信息”，并继续检索主动系统辨识与工具学习最近邻。[来源](REFERENCES.md)

**C. 假设。** 短交互可提供视觉看不出的动力学信息。竞争解释：模型识别工具ID；改好工具坐标标定就足够；探测只为系统留出了稳定时间；在线参数估计已能解决。

**D. 最小实验。** 固定一种推移或接触操作，先在仿真改变隐藏动力学并保留未见组合。比较无context、工具ID、正确工具坐标/作用点基线、显式系统辨识+控制、真实探测context、等长静止/错误/乱序context。尽可能设置外观相近但动力学不同、外观不同但动力学近似的条件。所有评测计入探测时间。

**E. 评价。** 冻结策略的适配收益、首次任务成功、总交互预算；与少量任务示教微调公平对比时报告更新步数和数据量。交换context必须检验其分布有效性。指尖触觉测到的是手—工具接触，不能直接视为工具—环境力；需核对夹持滑动、安装与工具变形的可辨识性。换工具属于跨工具，不自动等于跨机器人本体。

**F. 潜力。** 与机械背景契合，主要工程工作是可重复物理条件和标定。10月可先仿真筛选；若需要多个全新执行器、复杂安装与触觉布置，不作为本届第一选择。工具标定本身解决的问题应归为工程收益。

## D5：动作的“语义”能否按效果定义？

**A. 问题。** “拿起杯子”在关节轨迹上可以完全不同。是否能学习一种表示，让相同物体状态变化保持可迁移，同时仍保留足够的信息生成可执行动作？小模型何时真的使用示教context？

**B. 已有工作与缺口。** FAST 已做动作压缩token，LAPA 已学视频潜在动作，UniVLA 已做面向任务的潜在动作；“把动作变成向量/token”不是新贡献。ICRT表明上下文能力需要相应训练分布。候选缺口是接触阶段/物体效果监督的额外价值及其可执行边界。[来源](REFERENCES.md)

**C. 假设。** 表示物体相对运动、接触阶段与任务结果，可能比直接压缩关节序列更不受场景和路径变化影响。竞争解释：只是记住类别/语言标签；效果标签比基线获得更多信息；表示丢掉执行细节，聚类好看但控制变差。

**D. 最小实验。** 先固定一个小任务族，如拿起/放下/推移，在仿真改变位置、背景、物体实例与达到相同效果的轨迹。比较连续动作策略、轨迹压缩或VQ基线、加入效果/接触监督的方法；共享训练数据与解码器预算。若研究context，让目标只能通过示范区分，比较正确、错误、删除、乱序prompt，并核验推理阶段是否发生权重更新。

**E. 评价。** 留出组合的任务成功和效果预测、动作可执行误差、context替换对行为的影响。低维可视化只作诊断；需要无监督/相同标签预算对照，避免用人工效果标签制造不公平优势。

**F. 潜力。** 适合学校本机与仿真，真机只验证主要现象。与现有工作重叠较高，9月底应先读UniVLA全文。不承诺少量数据就能获得广泛语义或通用one-shot；跨任务不变性与控制细节之间的折中本身可成为问题。

## D6：预测未来接触，什么时候能改善决策？

**A. 问题。** 在接触修正中，策略只看当前历史是否足够？预测即将滑移/失去接触/卡住是否能更早选择有用动作？

**B. 已有工作与缺口。** 早期 deep tactile MPC 已研究触觉预测控制；TouchWorld、TacForeSight与TacPAC是更近的直接工作。“小型触觉世界模型+策略”已经存在。候选增量应是预测目标、时域和延迟在有限数据下的必要性，而非另起宏大世界模型名字。[来源](REFERENCES.md)、[触觉近邻](TACTILE_RELATED_WORK.md)

**C. 假设。** 对有短期先兆、执行存在延迟的接触失效，动作条件的短期预测可能有用。竞争解释：更多历史和参数足够；效果仅来自辅助监督正则化；预测对未见接触不准，反而误导。

**D. 最小实验。** 从D1数据训练小型动作条件模型，预测短期事件或紧凑状态，不先生成高分辨率视频。比较相同历史的反应策略、仅辅助预测损失、实际使用预测做候选动作选择，以及已知真实未来的离线诊断上界。动作候选集合相同；上界不进入实际部署或主成绩。

真实日志只有实际执行动作的后果，只能用于该动作的预测诊断；它不能提供所有候选动作的反事实未来。用于动作选择的oracle上界需在可从同一状态分别推进候选动作的仿真等明确条件中建立，并注明仿真假设。

**E. 评价。** 预测校准、未见条件误差、提前量、闭环成功和总决策延迟。保持预测和决策预算透明。仿真可用于判断什么时候需要预测，但不替代真实触觉外推验证。

**F. 潜力。** 若已有可靠接触日志可作为D1后续，单独新开会增加模型与评价负担。只提高事件分类准确率不能证明机器人控制价值。

## D7：SNN 是否真的适合当前边缘触觉链路？

**A. 问题。** 触觉数据稀疏变化时，事件驱动计算能否在相同误报率与闭环效果下减少响应时间和能耗？

**B. 边界。** 本轮没有完成SNN触觉方向的针对性最新文献核查，因此尚未建立可投稿的新颖性主张。GPU上模拟脉冲不能自动获得神经形态芯片优势；参数少、FLOPs少也不等于端到端更快。

**C–E. 最小验证。** 在同一Jetson、功耗模式、批量1与相同历史长度下，比较阈值+滤波、TCN/GRU和小SNN；必要时再比较小型状态空间模型。记录事件编码耗时、采集传输、推理P50/P95、能耗与误报/漏报，在线任务将动作接口延迟计入。功耗测量若只能得到板级功耗，应标明范围。

**F. 潜力。** 先作为部署测量或学习探索。若瓶颈是通信与执行，换网络未必改善机器人；不能用假设中的专用硬件性能为本届论文作保证。仅在实测有清楚现象且补齐文献后升格。

## 怎样选，而不是同时开七条线

| 条件 | 推荐行动 |
| --- | --- |
| 有稳定触觉日志与接触任务，尚不清楚触觉是否被利用 | D2诊断 → D1时序问题 |
| 人类采集链路已经可用，数据源是现有合作的核心 | 对齐合作边界后优先评估D3 |
| 主要机时在学校，真实触觉链路暂不可用 | D5或D4仿真先导；保留真机验证要求 |
| D1已有可靠数据且预测确实可能改变动作 | 再评估D6，避免同时扩多系统 |
| 强烈希望研究SNN但无专用硬件 | D7同平台实测，不预先设定一定更快 |

初步建议是D1+D2作为一个问题和诊断手段，D4/D5作为备选，D3随数据可用性调整。到10月底应根据证据确定一个主线；如果最近邻已解决同样问题，修改问题而不是只换模块名称。

这里“有机会赶上IROS”指工程与证据链有可能在时间窗内完成，不是对创新性、成功率或录用的保证。
