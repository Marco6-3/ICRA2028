## 1. 先固定我们在解决什么问题

当前问题是：**把触觉阵列压缩后，是否仍能准确、低成本地估计接触相关物理状态；历史是否提供当前表示没有的信息？**

11D 是观测描述，不是完整物理状态，也不是“任务是否成功”的标签。当前已经运行的学习实验只有：

| 实验 | 输入与目标 | 能回答的范围 |
| --- | --- | --- |
| LeFlexiTac | 本体状态与不同触觉表示，预测 action[t+5] − state[t] | 示范位置指令偏差的离线拟合 |
| TaF | 不同触觉表示，预测独立 ATI 的 [−Ty/Fz, Tx/Fz] | 保存单位下的力矩／法向力比估计 |
| 后续自采空间实验 | 触觉表示，预测工装／机械臂给出的 x、theta | 受控空间可辨识性，尚未执行 |

当前没有 Mamba、VLA、任务阶段分类或机器人闭环结果。下列路线优先服务于上述状态估计目标；未来预测、记忆管理是有条件扩展，不能预写成滑移预警或纠偏成功。

已有结果见 [OFFLINE_RESULTS.md](OFFLINE_RESULTS.md)：11D 的增量尚不可靠，总响应＋质心是必须保留的强简化基线。最终允许采用更小表示、学习表示或短窗模型，不要求维护“11D＋Mamba”。

## 2. 如何使用这份清单

- 先完成 Q0 数据与时间接口检查，再选满足数据条件的路线；不一次跑完全部组合。
- P1 是低成本表示／读出检查；R07 是独立的、受限 Stage-2P，不要求先把所有 P1 跑完。
- P2 仅在对应现象或数据条件出现后启动；P3 仅保留为后续候选。
- 每轮在开发集筛选，冻结候选、主指标、最小实用差异和预算后，才访问确认集。
- 已反复使用的公开测试集只作探索性结果。确认性结论应留给未使用的源记录／独立自采批次。
- 路线的“有效”包括在允许精度损失内更省资源；“不显著”不等于“等效”。
- [MATRIX.csv](../experiments/validation_routes/MATRIX.csv) 用于登记每条路线的状态；每次实际运行复制 [RUN_TEMPLATE.md](../experiments/validation_routes/RUN_TEMPLATE.md)，逐轮记录协议、结果与偏离。

## 3. Q0：接入任何时序模型前的数据要求

Q0 是接口正确性，不作为“改进算法”的成绩。

1. 从完整源记录重建时间轴，保留 source_id、episode_id、原始行号、sensor_timestamp、host_receive_timestamp。现有 TaF 脚本先按标签／接触条件筛行，不能直接把缓存中剩余的行串成连续序列。
2. 区分传感器可用掩码、接触有效掩码和监督标签掩码。ATI/Fz 等真值只能决定损失／评价资格，不能决定模型看到哪段历史、何时清空记忆或是否接触。
3. 标签无效时可以跳过损失，仍用当时可获得的观测更新状态。真实缺帧保留缺失标志与间隔，不用未来插值补齐。
4. 训练、验证、测试的完整源记录不交叉。真实独立 episode 边界重置状态；人为文件切片先核实连续性。不能把状态从训练传到验证／测试。
5. 接触释放不默认清空记忆；这一动作属于 R11 的实验变量。普通基线遵循预先冻结的 episode／间隔重置规则。
6. baseline、P_ref、缩放、阈值、几何映射和时间同步偏移只由训练／专用标定确定。在线无接触校准须对所有路线相同，接触中冻结。
7. 差分、EMA 和斜率只用当时及过去已到达的数据。训练当前标签的输入也必须满足真实到达时间；不能靠离线对齐把未来观测前移。
8. 第一轮使用固定、实测的采样节奏；如重采样，只用因果可用数据并对全部方法一致。把 dt 作为输入并不自动让标准 Mamba 具有物理时间等变性，其内部选择性步长不等于传感器时间戳。
9. 声称“有限 H 历史”时，EMA、差分、归一化状态和网络缓存都不能携带 H 以前的隐式信息。若保留流式预处理，只能称“相同流式预处理下比较网络记忆范围”。窗口 warm-up、损失掩码、训练展开长度、推理记忆跨度分别记录。
10. 验证前缀因果性、源记录隔离、重置一致性、时间间隔和流式／批量实现一致性。通过这些检查不等于模型有物理收益。

## 4. 表示名称与维度

下面只计算触觉描述维度。有效性／质量标志、dt、本体状态等必须另列，不以“11D”隐藏辅助输入。

| 名称 | 当前触觉描述 | 显式变化 | 触觉维度 |
| --- | --- | --- | ---: |
| ScalarCurrent | P' | 无 | 1 |
| Centroid3 | P', cx, cy | 无 | 3 |
| ScalarDelta | P' | ΔP' | 2 |
| CentroidDelta6 | P', cx, cy | ΔP', Δcx, Δcy | 6 |
| Physics8 | P', cx, cy, A', sigma1, sigma2, ox, oy | 无 | 8 |
| Physics11Legacy | Physics8 | ΔP', Δcx, Δcy | 11 |
| Cov7 | P', cx, cy, A', Σxx, Σxy, Σyy | 无 | 7 |
| Cov10 | Cov7 | ΔP', Δcx, Δcy | 10 |

现有代码中“Scalar”实际包含差分，“Scalar＋centroid”也包含三个差分；不能把归档成绩当作严格 1D／3D 当前帧输入成绩。原始 11D 使用每帧差值；变化率版须另取名称，例如 Cov10Rate。

二维协方差只有三个独立分量。原形状编码的四个量由它导出，替换仅改变参数化；epsilon、弱接触和舍入误差需保留检查，不宣称全域数值精确等价。原代码已有各向同性方向保护。

## 5. 各路线的验证卡

### R01 — 三通道协方差替代四通道形状编码

**问题／假设**：已有四通道编码是否引入不必要的冗余或学习难度？直接输入 Σxx、Σxy、Σyy 可能减少计算和拟合负担，但不会增加信息。

**改动**：Physics11Legacy → Cov10；保持 P'、A'、差分定义、阈值、滤波、坐标与监督目标一致。

**最小实验**：同一线性／小 MLP 比较 Legacy11 与 Cov10；CentroidDelta6 为简化参照。以后才在同一 Mamba 下重做此比较。学习瓶颈若用于主张“物理优于学习”，需有对应维度版本，不能只拿 10D 与未调优 11D 比。

**指标**：同一独立标签的误差、低样本表现、描述计算 P50/P95、弱接触数值稳定性；协方差计算也计入成本。

**判读**：误差相近但计算更省可作为简化选择；无可靠差别则仅称参数化替代；若恶化则保留原编码。不能写成更充分的物理信息。

### R02 — 显式差分是否必要

**问题／假设**：在流式模型已经看到过去时，三个差分是有益提示还是冗余／噪声放大？

**改动**：先 Cov10 vs Cov7；单独复核 Physics11Legacy vs Physics8。不要把 Legacy11 vs Cov7 的变化全部归因于差分，因为它还改了形状编码。

**最小实验**：相同主干、同一输入可见历史、同一训练／读出预算。保留短窗小模型，防止把两帧变化当成长记忆贡献。无差分版本也不能偷偷丢失接触标志。

**指标**：独立状态误差、标定噪声下误差、动态响应滞后、参数／时延。

**判读**：去差分不降低实用效果则优先更小输入；差分有益则保留并定位于短时线索。若收益仅出现在可人为制造的噪声上，不推广到真实接触。7D 无差分不等于整个系统无历史，仍须审计预处理状态。

### R03 — 时间一致的变化特征

**问题／假设**：每帧差值在丢帧／采样间隔变化时含义不一致；逐点除 dt 又可能放大噪声。

**改动**：分开比较相邻差值、差值／实际 dt、固定过去时间窗的因果斜率。窗口长度用秒／毫秒定义，只在开发数据选定一个；窗口不足和接触无效要显式标记。改变滤波时为所有表示提供同样预处理，或把滤波收益单独报告。

**数据**：优先真实时间戳；从连续记录做因果丢帧压力测试可作补充，不能称为跨硬件验证。需要同步的动态物理标签。

**对照／指标**：固定频率数据作为参照；比较状态误差、不同间隔下退化、估计滞后。评价速度相关结论时保留真实目标速度变化。

**判读**：严格固定 dt 且线性标准化时，除 dt 主要是常数缩放，不预期凭此涨分。斜率若靠延迟换精度，必须报告取舍；无实际时间问题就不优先启动本路线。

### R04 — 响应参与面积替代阈值面积

**问题／假设**：A' 的二值计数是否因小响应跨阈值而抖动？可测试幅值参与率：

$$
A_{\mathrm{eff}}=\frac{(\sum_i w_i)^2}{N\sum_i w_i^2},\qquad P>0.
$$

非负权重下，均匀激活 k 个 taxel 时该量为 k/N；无接触填零并保留标志。分母 epsilon／无效条件在标定阶段冻结。

**改动**：只用 A_eff 替换 A'，维度不变；另设完全去掉面积通道的简化参照。第一轮不同时更改阈值、滤波和形状编码。

**数据／指标**：稳定保持、不同面积／形状、弱接触重复；比较独立 x／theta／力矩比误差、重复性、阈值敏感性。

**边界／判读**：这是响应分散程度，不是几何接触面积；仍会受到上游截断影响，也可能丢失有用边缘信息。若只使曲线更平滑却降低物理估计准确性则不采用。

### R05 — 明确质量信息，避免把不可靠观测当真实状态

**问题／假设**：弱接触、坏点或饱和时的异常几何是否误导模型？

**现状**：当前／前帧有效标志和跨无效接触的质心差分屏蔽已实现，不把它们重新包装成新改进。

**改动**：按实测问题预先选择至多两个附加质量量，例如总响应相对标定噪声、已知 ADC 饱和 taxel 比例。无设备上限就不捏造饱和标签。质量不等于物理状态真值，也不默认为“越低越应清空历史”。

**对照**：已有标志 vs 额外质量量；所有 Scalar／Physics／Raw／Learned 基线都获得相同质量侧信息，另外报告不加侧信息的结果。输入总维度单列。

**数据／指标**：真实弱接触、稳定接触和饱和边界记录；分条件误差、跨 session 泛化、可用覆盖率。不能仅通过删除难样本提高分数。

**判读**：质量量若仅编码 session／硬件身份、普通数据无增量或总量本已包含同样信息，则不增加通道。

### R06 — 几何基线加残差读出

**问题／假设**：TaF 当前目标与接触偏心有关，模型是否主要在重新学习一个简单几何映射？先建立可解释基线，再检查是否有剩余动态信息。

**改动**：

$$
\hat y_t = B[c_x,c_y]^T+b+r_\theta(s_{\le t}).
$$

B、b 仅由训练／专用标定拟合并冻结。对残差通路分别测试当前帧小模型和相同预算的时序模型。基线质量要单独报告。

**对照**：纯线性几何映射、相同输入的直接非线性读出、几何＋残差。固定同样监督样本、训练预算；避免给某组额外测试标定。

**指标**：完整源／trial 的绝对误差，真实动态变化误差，源内和源间偏置分解。窗口均值消除只用于回顾性诊断，不能输入模型或重新选模；静态／零变化参照必须保留。

**判读**：残差若几乎不可预测或纯几何已足够，采用简单读出。ATI 坐标、剪切、接触高度与安装偏置未核实前，不把 B 当精确物理定律或把标签称为毫米 CoP。

### R07 — 同主干的表示×记忆探针

**问题／假设**：空间表示的较长历史，是否带来标量历史／当前空间表示没有的独立状态估计价值？

**首轮范围**：遵循现有 Stage-2P 四路比较：Scalar、Scalar＋centroid、Physics11D、Learned11D → 同一 Mamba-style 主干。预先写明用的是 current 还是 delta 版本；为保留原 11D 对比，其他分支须有相同的原始过去帧可见范围。学习瓶颈只用训练集，明确逐帧或因果两帧编码，不能一组看更多历史。

**比较轴**：四种表示都保留相同短期范围的当前读出；增加一个统一定义的短窗对照，再比较流式 Mamba。先固定一个主干设置和一个物理历史预算，资源允许时只增加一个预注册历史预算。所有分支共享隐藏维度、训练预算和决策率，单列投影层差异与实际总参数／延迟，不能声称输入维度不同却参数严格完全相等。

**可选后续**：R01/R02 的 10D／7D 候选须在开发集选定、写入新一轮协议后进入，不在看测试分数后不断扩充原 Stage-2P。若要主张 Mamba 优于其他记忆方法，再加入一个合理的轻量时序基线，而不是首轮扫描很多架构。

**目标／指标**：可先沿用 TaF 独立物理量；保留全部接触帧指标与预先冻结的动态诊断，不能只挑有利稳载窗口。确认集逐源／trial 配对误差、历史长度带来的增量、流式推理 P50/P95。若用 EMA，遵守 Q0 的有效历史定义。

**判读**：记忆增益和空间增益分开报告；检验相对于各自短期读出的增量。仅 Mamba 优于 MLP，不足以声称表示×记忆交互；低阶状态同样好则简化表示；只有降噪收益则不声称长时物理记忆。当前静态自采数据可支持 R01 等，不保证有适合本路线的动态信息。

### R08 — 用动作与本体历史解释触觉变化

**问题／假设**：相似触觉变化可能来自主动加载，也可能来自外界扰动；已执行动作是否帮助判断？

**改动**：在固定触觉输入外加入同步的 q 历史与严格过去的执行动作。只有 t 时刻已到达／已发布的数据可用；动作命令与实际执行量分别记录。LeFlexiTac 已有当前本体状态和后向变化率，不能把这两项重复当作新增。

**数据**：同步本体／动作和独立状态标签；主动加载与外部扰动需有相近的当前条件，并随机化起始时刻。数据没有真实动作记录时保持待数据，不根据标签反推“动作”。

**对照**：本体／动作 only、触觉＋现有共同本体输入、触觉＋动作历史；所有表示共享相同新增侧信息和时间范围。

**指标／判读**：状态误差、匹配当前条件后的歧义子集、跨动作程序泛化。若模型只是识别固定时间脚本，不声称理解接触因果。未来 action[t+5] 若是标签，绝不能被送回输入。动作条件触觉预测已有工作，本路线不以“加入动作”主张首创。

### R09 — 独立物理目标的预测辅助训练

**问题／假设**：只拟合当前标签是否不足以训练有用历史？辅助预测未来独立物理量，可能促使隐藏状态保留动态信息。

**改动**：固定 R07 中一个表示／主干，比较当前估计损失与“当前估计＋少数未来时距损失”。第一轮固定一个时距，开发集至多比较零与一个非零辅助权重；预算另记。未来真值只作训练目标。

**数据条件**：真实连续动态及可靠同步。相同当前状态下，如果未来执行动作／外部加载未知且不同，未来目标可能不可预测；须明确是在既定可见动作计划下预测，还是在数据中的动作分布下预测。离线未来真实动作不能伪装成在线可用计划。

**对照**：无辅助、持值预测／简单线性外推、相同算力训练；评估当前估计是否被损害。目标是独立 ATI／姿态标签，不以预测自身 11D 算子的准确率证明物理理解。

**指标／判读**：当前与未来误差同时报告、真实动态子集、跨时间程序泛化。如果仅改善未来平滑曲线而无当前或目标任务价值，保持为预测实验，不升级成控制收益。已有触觉预测工作较多，辅助损失本身不是新颖性证明。

### R10 — 少量局部空间信息补足物理压缩

**启动证据**：开发数据中找到当前或历史物理描述相近，但独立物理标签确实不同的样本；差异需超过测量噪声。仅 raw 图不一样不够。匹配规则、容差和归一化先在开发集冻结；测试标签只用于最终分层评价，不选模型或样本规则。

**改动**：固定物理输入，先添加固定 2×2 区域的归一化响应份额；四份额总和为一，只需三个独立通道。若简单局部池化仍不足，再单独试预注册小维度的学习补充分支，不同时搜索任意网格和维数。

**对照**：原物理输入、纯 learned 同总瓶颈维数、物理＋区域通道、合理 Raw 小编码器；共同过去范围、训练与预算一致，报告投影成本。固定网格原点与方向，不按测试接触位置移动网格。

**指标／判读**：独立标签误差、压缩歧义子集、全体测试误差、低样本与成本。若粗网格已足够则不加学习分支；若无真实歧义或信息补充无收益则停止。原数学反例只能证明可能丢信息，不保证此网格能解决所有反例，也不证明真实控制失败。

### R11 — 接触变化下的记忆管理

**启动证据**：释放／重接触后出现可重复的历史干扰，或清空全部历史损失可复用信息；普通持续接触数据不足以支持此路线。

**假设／改动**：局部接触几何记忆和在相同对象／表面条件下可能可复用的响应经验，或许需要不同保留规则。先测简单清空／不清空，再考虑分开的隐藏状态与选择性保留；不直接从“理论上有迟滞”跳到双记忆网络。

**数据**：独立标注接触转换用于评价；在线边界判断来自传感器可获得信息。需要重复加载→释放→换位置再接触，以及条件改变的对照；接触几何、对象／表面是否相同的记录用于分组真值，不无条件作为部署输入。

**对照**：普通 Mamba、固定滑窗、检测到释放时统一清空、选择性保留；所有方法有同样接触标志与侧信息，分支拆分保持近似总参数预算。单列真实边界 oracle 只作上界诊断，不参与可部署成绩。

**指标／判读**：重接触后的状态估计误差与收敛时间、持续接触误差、边界误检敏感性。普通 Mamba 或统一清空已足够则不升级；不能把保留某个隐状态自动解释为学到了摩擦系数。Mamba 已有选择机制，增加门控本身不是贡献。

## 6. 建议执行顺序与组合验证

### 第一轮：建立可靠参照

完成 Q0，先在同一开发数据上复核 CentroidDelta6、Physics11Legacy，以及合适的 Raw／Learned 对照。R06 的纯几何基线可同时用于判断标签是否主要由质心决定。

随后只做 R01、R02 的独立小消融。R03/R05 有实测问题才启动；R04 保留为一个固定面积替代项。不要把十一条路线做成全因子网格。

### 第二轮：受限时序探针

原始顺序数据确有额外历史线索时，按 R07 固定四路主对比。可与自采 Stage 0/1 并行；不要求先完成全部候选消融，也不把允许 probe 写成表示阶段已经通过。

### 第三轮：数据驱动的扩展

- 有同步动作且主动／被动歧义明显：考虑 R08。
- 有稳定动态真值，当前读出不足：考虑 R09。
- 有真实物理压缩歧义：考虑 R10。
- 有重接触记忆问题：考虑 R11。

这些分支可以分别停止，不用为了故事完整全部做正。

### 最多先组合两个候选

开发集选出至多两个单项有实际价值且兼容的改动 A、B，冻结后比较四组：基线、A、B、A＋B。同一数据、相同模型／训练预算，报告组合是否互补、重复或相互抵消。

例如 Cov10 参数化与有效面积可以组成一个 2×2；但同一条“有／无差分”轴上的互斥版本不能当作两个模块叠加。不要只发布最好的 A＋B 而隐藏单项和负结果。

这四组必须在新的确认集一次性评价；根据结果再改组合即成为下一轮探索，需要新的确认批次。若同时对多个候选作正式显著性主张，要预先声明多重比较处理或限定一个主要比较。

## 7. 统一评价与决策规则

### 独立目标与指标

- TaF：保存单位的双分量误差。首选每源记录内 RMSE 后等权平均；预先固定跨种子汇总方式，报告逐源配对差及区间。当前坐标／单位限制继续保留。
- 自采：分别报告 x 与 theta 的 MAE；如只选一个主要指标，需提前声明，不能把不同单位直接平均。
- 动态：只有同步独立真值可用时才报变化追踪、滞后或事件误差。TaF 窗口均值消除属于离线评价分解，不作为在线输入。
- 效率：相同设备、批量一、相同 warm-up，分别报预处理、编码、流式更新、读出的 P50/P95，以及参数、内存、训练成本。网络耗时不等于事件到动作生效时延。
- 泛化：只有物体／表面／批次身份核验后，才称对应 OOD。源编号不自动代表新物体。

### 运行前必须填写的决策量

在 RUN_TEMPLATE 中填写主要比较、最小实用改善 delta、允许退化 margin、确认集、历史范围、种子列表、候选数、训练步数和总计算预算。它们由开发／标定误差和实际用途决定，不编造通用 5%／0.5ms 成功门槛。未填写的轮次只作先导，不作确认性判决。

已有 Task 1 的 3% 非劣 margin 仅适用于其定义的 temporal non-regression，不能直接套用到所有 RMSE、角度和空间任务。

### 结果状态

| 状态 | 含义与下一步 |
| --- | --- |
| 支持保留 | 达到预注册实用收益／成本取舍，并在独立单位上有相应证据 |
| 简化优先 | 在预设等效／非劣边界内，更小或更快的方案足够 |
| 无明显收益 | 该设置下未发现增量；若区间宽，标明不能排除潜在价值 |
| 证据不足 | 有效独立样本、标签精度或统计精度不足，先解决可识别性 |
| 实验无效 | 泄漏、时间轴损坏、干预未生效等；修复后新建轮次，不当方法负结果 |
| 暂停／放弃 | 条件不满足、超过预算、收益不足或成本不值得；保留记录 |

不得用种子数量冒充独立物理重复。逐源／trial 的相关性需要按最高可靠独立单位汇总；同一 session 的 trial 可能仍相关。

## 8. 采集时顺手保留什么

现有 [FlexiTac 采集协议](../experiments/flexitac_spatial/PROTOCOL.md) 的 24 条 pilot／108 条正式矩阵仍是空间实验，不自动扩展成这里所有路线的数据。

共同保留 raw 全序列、空间布局／坏点、基线与阈值版本、sensor／host 时间戳、session／trial／完整源记录 ID、独立真值及其时间戳。增加字段不等于已经有对应动态真值。

| 支持路线 | 额外需要的数据 |
| --- | --- |
| R01/R02/R04/R06 | 重复位置／倾角／载荷、训练标定与独立空间真值 |
| R03 | 实际帧间隔、缺帧原因、动态参考 |
| R05 | 噪声标定、设备饱和界限、真实弱接触记录 |
| R07/R09 | 连续加载／保持／卸载及独立动态真值；当前状态相近但历史不同的候选过程 |
| R08 | 已发命令、实际动作／本体状态及同步信息 |
| R10 | 不同真实局部接触分布，以及与其相关的独立目标差异 |
| R11 | 释放与重接触、表面／位置变更记录、转换评价标签 |

不从触觉阈值生成“接触类别”后，用同一触觉输入分类成绩证明物理理解。改变未来加载程序的对照，应避免模型仅记住时间、操作者顺序或固定动作脚本。

## 9. 来源、主张与新颖性边界

以下是方法来源／已有覆盖范围，非本项目复现。核对日期 2026-10-06；没有完成穷尽性查重。

| 来源 | 本次已读范围 | 对路线的约束 |
| --- | --- | --- |
| [TacMamba](https://arxiv.org/html/2603.01700v1) | 硬件、方法、实验文本 | 已有标量触觉流式记忆；R07 借用范式，不把输入改维度当创新 |
| [Mamba](https://arxiv.org/abs/2312.00752v2) | 摘要 | 已有输入相关选择／遗忘；R11 不能仅以“门控”声称新颖 |
| [Action Conditioned Tactile Prediction](https://arxiv.org/abs/2205.09430v2) | 摘要 | 动作条件触觉预测已有研究；R08/R09 需更具体证据 |
| [TacForcing](https://arxiv.org/html/2608.25798v1) | 方法与实验文本 | 已有执行时触觉条件与动作块对齐；状态估计不是已实现闭环 |
| [PACE](https://pace-insertion.github.io/) | 官方项目摘要与方法概述 | 已有持续状态、事件纠正、未来后果三种角色；不能用宽泛“快慢分工”认证创新 |
| [ResTacVLA](https://arxiv.org/abs/2607.03387v3) | 摘要 | 已有视觉预测与实测触觉的残差表示；R06/R10 不是该方法复现，也不能泛称首次残差触觉 |

R01/R03/R04 是可检查的参数化／信号处理提案；其他路线也只是候选工程或研究假设。若以后将某条升级为论文贡献，需针对实际发现再核对最近方法与消融。当前不承诺成功率、首次、SOTA 或投稿结果。
