# 验证方案：历史何时帮助执行中的动作修正

状态：方案，未运行。2026-10-05。

## 先选能区分解释的任务

| 任务族 | 为什么需要历史/反应 | 观测与成功定义 | 主要混淆 |
| --- | --- | --- | --- |
| 遮挡插接与卡扣就位（首选） | 当前力近似，但是否经过卡扣/接触释放影响下一动作 | 是否真正就位、误判完成率、峰值接触力、卡死/回退次数 | 机械导向可让任务变简单；视觉可能已泄露状态 |
| 受扰曲面擦拭/持续接触 | 需要根据接触变化恢复法向接触、区分主动动作和扰动 | 覆盖率、力误差、脱离接触时间、扰动恢复延迟 | 简单力控制已很强；擦拭轨迹本身可解释结果 |
| 多次接触后的确认操作（诊断） | 区分事件计数/任务阶段记忆与连续接触控制 | 事件识别、计数错误、最终操作成功 | 单纯计数成功不证明高频控制改善 |
| 无扰动、状态可见或低动态版本（负对照） | 检验不需要复杂记忆时的代价 | 成功率、延迟和资源开销 | 不应人为隐藏所有简单线索来制造优势 |

同一任务应有不同材料、刚度、配合间隙、摩擦/表面、运动速度或扰动时刻。先挑对结论最关键的变量，避免一开始全因子穷举。仿真需说明接触/传感器模型能否表现所需事件；不能把理想接触力等同于真实传感器输出。

## 分离“记忆收益”和“更新更快”

先固定一个可复用主策略及快策略接口，使用相同示教、动作空间、当前观测、历史可见范围定义与训练预算。

| 对照 | 用途 |
| --- | --- |
| 无触觉/视觉策略 | 辅助判断触觉价值，不作为唯一强基线 |
| 当前触觉 + 相同执行时刷新 | 排除仅由刷新频率带来的提升 |
| 固定短窗，含多个窗长 | 检验更多历史和窗口选择是否足够 |
| 低通/变化率/事件检测与简单衰减 | 检验学习型复杂记忆是否必要 |
| 持续状态的因果 GRU | 公平的流式递归基线，不能每步重算整段历史 |
| 有限窗口因果 Transformer | 避免只与不合理的全历史重算实现比较 |
| 候选选择性记忆 | 检验保留/遗忘机制的增量价值 |
| 适用时的力/阻抗控制 + 相同慢计划 | 排除基本闭环控制已能解决主要困难 |

工程基线优先核查 RDP/ImplicitRDP，依据可用实现和传感器选择一个先运行。若最终主张针对 VLA，需在适合的 VLA 上验证；小型 DP 的结果不能自动外推所有 VLA。要与 TacForcing/T-Rex 比较时需报告实现是否忠于原文，适配版本不能冒充原论文复现。

## 先导实验与决定

1. 采集或复用少量完整轨迹，核查历史是否含有当前观测缺少、且可能影响动作的事件。离线可解码只用于筛选。
2. 运行当前帧、短窗、GRU 的闭环比较；不要先搭建昂贵新模型。
3. 若有可信历史收益，再检验一个选择性机制；若无收益，先检查任务、传感器、演示覆盖和基线实现。
4. 若简单滤波/GRU 已覆盖优势，保留负结果，缩小主张或改问“何时需要多长记忆”，不继续为 Mamba 找理由。

先导用于估计变异与确定正式样本规模，不以少量成功视频判定。正式训练建议至少 3 个独立种子起步；根据方差与资源调整，并记录理由。试验按物体/批次/episode/种子组织，不能把帧或重叠窗口当独立样本。

## 有区分力的消融

- 相同历史时长与编码尺寸，比较保留策略，另报参数量与训练开销。
- 移除输入依赖选择性，或换固定遗忘；容量明显变化时补容量对照。
- 在安全可重复的评测中控制事件间隔、接触状态切换和信号噪声，观察何时该保留/清除。
- 比较当前帧、固定窗、选择性状态对未见事件间隔和材料的鲁棒性。
- 记忆重置、历史时间打乱仅作为诊断：会引入分布外输入，不能单独证明机制。
- 如声称行动条件化有价值，让所有比较组获得相同 q 与已执行动作，再消融这些输入。
- 固定记忆方式后单独改变刷新率；固定刷新率后单独改变记忆方式。

## 指标、划分与时间因果性

主要指标：每个任务预定义成功率/连续质量指标；反应延迟与危险/失败接触作为并列指标。报告物理事件发生到新动作实际生效的端到端延迟，至少包含中位数、P95，另列采样、传输、编码、策略和执行耗时。只报网络 forward 不足以支持“反应更快”。

训练/验证/测试按完整轨迹、对象和采集批次划分；未见材料/间隙或扰动条件单列。验证集可调超参，锁定模型后测试集只读。给出效应量、区间与失败类型，不只报平均成功率或显著性。

每个传感器记录采样时间与到达时间；动作记录下发与实际执行时间。所有输入在决策时已到达；episode 开始重置隐状态。归一化参数仅由训练集估计。不能通过双向编码器、未来帧插值、完整 episode 统计或教师强制将未来触觉放入在线策略。

仿真真实摩擦/接触状态默认仅用于训练完成并锁定模型后的只读诊断，不参与输入、选模和最终测试调参。

## 投稿前证据门槛

- 有最接近且认真调优的记忆/反应基线，不只对视觉模型。
- 主要差异可跨种子与未见条件复查；报告失败与代价。
- 关键机制消融能改变判断，未证明部分明确降级为解释或假设。
- 要主张真实接触操作，需真机闭环证据；只有仿真时相应缩小主张。
- 数据、版本、配置和推理时延可追溯，不能用论文中的指标充当本项目结果。

这些是形成可信论文的工作标准，不是录用保证。
