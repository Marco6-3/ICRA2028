# ICRA2028：UMI + FlexiTac 数据采集与真机闭环研究计划（2026-11-05）

> **状态：方案 v0 / 待硬件 Pilot 校准后冻结正式评测协议。**
>
> **本轮正式执行决策**：暂不进行强化学习（RL / PPO / SAC / 在线残差 RL）；先将真实物理可观测性、跨时段数据稳定性、小样本表征学习、机器人闭环抗扰四件事做扎实。原 Stage 4 / V2.2 的 RL 代理实验与审计作为**历史归档**保留，不把它作为本次真机方案的前置条件，不改写已有代码、结果或负结果。
>
> **关系**：本计划是 [Stage 3A](STAGE3A_REAL_ROBOT.md) 与 [真机执行协议](../experiments/real_robot_reflex/PROTOCOL.md) 的当前执行补充；不取代历史 [范围记录](ICRA2028_MINIMAL_PAPER_FREEZE.md) 的实验事实。数值样本量为**候选预算**，不是已执行实验、功效分析或预注册阈值。

## 1. 核心科学问题与待证假设

**主问题**：低成本法向触觉阵列的物理结构化表征（BPI-MCF / CMQ-BPI-MCF）能否在**保留真实持续载荷与载荷反转信息**的同时，缓解跨时段、跨预紧条件下的无关分布偏移，进而降低模型学习所需数据并改善真实机器人 Anti-Tilt / Anti-Slip 闭环性能？

- **H1（可观测性）**：在给定传感器、柔性层、指尖几何、摩擦与加载范围内，部分外部偏心载荷会产生可重复、可区分的法向空间压力变化；**不假定法向阵列可唯一反演剪切力**。
- **H2（稳定性）**：参考帧、预紧归一化及双指分解**可能**降低基线偏置和预紧敏感性；不能声称彻底免疫蠕变、温漂或装配差异。
- **H3（保真度）**：去漂移与变化保真存在权衡；对**持续加载、卸载恢复、方向反转**分别测量信号保持能力。特别针对 V2.2 历史 b2 反转后的即时方向识别不足开展真机检验。
- **H4（学习与控制）**：在公平的训练预算、动作权限和独立 Session 评估下，结构化表征**可能**具有更高样本效率、较低推理开销和更好抗扰控制；不预先规定胜过 Raw 的结果。

**不宣称**：传感器物理精度改善、无标定真值力测量、跨设备/跨批次泛化（如未测试多个设备）、零误触发、10% 数据必胜 100% Raw、亚毫秒端到端延迟、已完成真机部署或在线 RL。

## 2. 三平台职责与边界

| 平台 | 目的 | 必须避免的混淆 |
| --- | --- | --- |
| **A：手持 UMI 夹爪 + 双指 FlexiTac** | 自由示教、多 Session 原始视觉-触觉数据；可**固定在夹具上**做受控加载 Pilot | 人类手部动作、接触变化与外力混杂；没有独立 F/T 不标注真实剪切力 |
| **B：真实机械臂平行夹爪 + 同系列双指 FlexiTac（候选 FR3 / Franka Hand，待实验室确认）** | 有物理真值/受控扰动的 Anti-Tilt、Anti-Slip 与闭环响应 | 不假定 UMI 的宽度、刚度、装配、控制频率与机器人一致 |
| **C：Isaac Lab / PhysX** | 开发与排错、受控消融、安全边界探索；必要时训练非 RL 的监督/模仿策略 | 仿真的接触场并不替代真实 FlexiTac 的法向—切向耦合证据 |

**硬件 Gate 0（先于采样）**：确认 UMI 可安装双指 FlexiTac、传感器有效网格和方向、覆盖层/背板几何、线缆布置、供电/串口/驱动、夹爪位姿/宽度可测；机器人端能否复用相同传感指尖或相近接触堆叠。传感器力学标定、实际触觉帧率、时间同步与可安全的加载范围均**实测后再确定**。

若 UMI 本体没有独立夹持力读数，`gripper_width` 只视为位移/宽度，不可冒充握力或预紧牛顿值；预紧分档应使用独立力传感或可验证的加载代理并报告其局限。若只有单指阵列，不得直接宣称完成双指 sym/anti 机制验证。

## 3. 执行路径与 Go / No-Go

### P0 — 双指传感器集成与测量校准（建议 10–20 条试次）

- 先记录无接触零点、重复接触、接触/松开、已知位置局部压载、双指坐标轴与增益差异。
- 校核 taxel 排列、饱和/坏点、触发阈值与基线锁定时刻；验证 `k_base=5` 帧是否落在**稳定预紧而不是闭合过渡段**。
- 相机、FlexiTac、UMI 位姿/宽度各自保存**原始时钟时间戳**；用可见且可测的同步事件估计时钟偏差与漂移，不强行按样本序号一一对应。
- 可视化双指 raw heatmap、总压力 proxy、CoP、面积、左右差异、丢帧率与加载/卸载曲线。
- **Go 条件**：设备与数据链路可重复，坐标符号清楚，基本触觉响应与独立测量相符；否则先修硬件/标定，不推进统计结论。

### P1 — 固定 UMI 的受控物理可观测性及跨时段稳定性

- 将 UMI 夹爪**固定**到刚性夹具；使用机械/砝码/滑轮等可重复装置加载，避免把人工手拉当作定量真值。
- **条件**：无扰动，+Fx、-Fx、+Fy、-Fy（依据夹爪坐标系和可实现几何冻结）；每个试次记录稳定预紧、受扰、保持、卸载恢复。分别增加**持续加载**与 **+→− 反向加载**专门试验。
- 分层改变 3 档预紧、不同采集 Session（尽量跨天），记录温度/贴装、物体、接触几何、载荷大小和偏心距；能用独立 F/T 与光学位姿真值时优先使用。
- **候选基础矩阵（不含追加反转/长保持）**：3 Session × 3 预紧 × 5 载荷条件 × 6 独立重复 = **270 trials**。在 Pilot 后可因成本或方差调整；不把 270 当成有统计功效保证的数字。
- **首要诊断**：零载漂移曲线、相同载荷条件跨 Session 的特征分布、反转后符号正确率与延迟、持续载荷保留率、卸载回零、误触发率（带观察时长）。
- **Go 条件**：至少一个感兴趣的空间扰动在独立重复中可重复、可区分；如无法辨识，先分析接触耦合或改几何/任务，不能靠更复杂网络补出不可观测信息。

### P2 — 自由 UMI 示教与监督表征评测（建议试点 60–120 条）

- 选择与闭环任务接近的 2–3 种操作：拾取保持、受扰搬运、精细放置；具体对象、轨迹范围和示教员在 Pilot 后冻结。
- 记录完整连续原始时序：双指 tactile、视觉、UMI 位姿、夹爪宽度/状态、可获得的动作或时间差分轨迹、事件标签、失败/失效标记；绝不从表征反向重建“Raw 真值”。
- **UMI 数据用来扩展接触状态覆盖与训练表征/模仿策略，不自动成为理想机器人抗扰动作标签**。若要训练恢复动作，需要定义可核验的监督来源（机器人安全教师、独立优化控制器或可映射动作），明确手持—机器人动作映射假设。
- 所有表征从**同一批 raw tactile trials**离线计算：真正全阵列 **Raw Taxels + 合理 CNN/MLP + temporal backbone**、Scalar、Standard Sliding-Window MCF、BPI-MCF 32D、CMQ-BPI-MCF 48D；可选加入 creep-only 与 sym/anti-only 消融。
- **不能把旧 `Raw_State4_16D` 当作 Raw Taxels 基线**；Raw 也允许合理的训练集归一化、历史信息与调参预算。
- 监督任务首选**有独立标签的**四向分类、受载/卸载/反转事件检测与（存在独立 F/T 时）力/力矩回归。多模态动作模仿为补充，单独报告。
- **训练/测试**：至少留出完整新 Session 作测试；所有划分按 trial / session / object 而非随机帧，训练集自身再做 10%/25%/50%/100% data scaling；对比例抽样与训练种子重复，不挑最优单次曲线。
- **评价**：trial macro 准确率/混淆矩阵、反转后窗口指标、漂移及类内方差/类间分离量、跨 Session 性能退化、数据量—效果曲线、编码+推理延迟与资源。t-SNE/UMAP 只用于辅助展示，不能替代定量统计。

### P3 — 真实机械臂抗扰闭环（保留原 Stage 3A）

- 首先在同一机械臂、同一传感器安装/标定、同一物体和外力加载协议上，跑 **Fixed / Nominal、Scalar Reflex、BPI Reflex、CMQ Reflex**；Standard MCF、真正 Raw CNN Reflex 和 High-Grip 作为补强对照。Baseline 不能因输入维度不同而获不同外部真值权限。
- **先在安全接口允许的条件下完成 1D gripper 控制**；后续若平台可安全进行二维腕部顺应，才在**所有比较模型可用动作权限一致**的前提下扩展到 3-DoF，不把 1D 与 3-DoF 改进混在表征收益中。
- 对于非 RL 控制器，优先固定 nominal + 可解释的阈值/反馈规则，或使用**明确来源的监督/BC**训练轻量策略；不进行 PPO/SAC，也不把现有 Stage 4 代理 score-function 精调称为真实在线 RL。
- 主要测试 Anti-Tilt / 偏心扰动，其次 Anti-Slip；闭环前冻结模型、增益、门限、动作幅值/速率限制、输入历史和测试工况。
- **主要结果**：trial-level 最大滑移/倾角、恢复时间、掉落率、峰值与积分夹持代价、静默误触发（含时长与置信区间）、sensor→actuator 实际延迟；标明控制器命令实际下发频率与执行器反馈频率。
- 使用独立测试 trial 和成对重复试验，报告不确定性、异常试次与代价/收益权衡；不预写“零滑移、零误触发、必然优于 Raw”。

**本轮暂不做**：正式 PPO/SAC、在线 Residual RL、VLA/大模型集成、完整插孔任务成功率宣称、为追求论文图表而扩展大量任务。历史 V2.2 归档保留供以后研究，但**不是** P0–P3 依赖项。

## 4. 统一记录协议与数据划分

建议目录（不代表已创建实际数据）：

~~~text
data/real_world/
  calibration/
  controlled_loading/
  umi_demonstrations/
  robot_rollouts/
  processing/
~~~

每个记录文件至少包含（有缺失就显式标为 unavailable 而非填入猜测）：

| 类别 | 最小字段 |
| --- | --- |
| 唯一定位 | `session_id`、`trial_id`、`platform`、`condition_id`、`split`、`schema_version` |
| 真实时间 | `sensor_timestamp`、`host_receive_timestamp`、`camera_timestamp`、`controller_timestamp`（各自时钟域、校正方式） |
| 原始模态 | `tactile_left_raw`、`tactile_right_raw`、相机帧/路径、`gripper_width`、位姿/关节（可用时） |
| 条件/独立真值 | `load_direction`、`load_magnitude`、`offset`、`preload_level`、`external_wrench`、`object_pose`、`slip`、`tilt`（须注明真值来源） |
| 控制时序 | `nominal_command`、`residual_command`、`final_command`、命令和实际执行器反馈时间戳（仅机器人端） |
| 数据质量 | `valid_mask`、`invalid_reason`、`saturation_flag`、`dropped_frames`、传感器版本/安装方向/温度（若有） |

- 原始数组、相机/标定元数据保持只读；派生特征写入带**算子版本、参数哈希**的独立处理产物。
- 提前冻结独立测试 Session 与加载条件；归一化、参数搜索、早停、类中心/Ridge 拟合只能使用训练/开发数据，不能看最终测试后调整。
- 记载每条 trial 的硬件配置、同步误差、失败原因和原始文件校验和；试次是独立统计单位，连续帧不是独立样本数。

## 5. 研究风险与对应检查

| 风险 | 检查/应对 |
| --- | --- |
| 锁参考帧抵消开始时偏置，却不能消除 trial 内慢漂移 | 比较无载静置、长保持、卸载恢复；报告时间窗依赖 |
| CMQ 过滤慢漂时损失持续剪切或反转信号 | 按载荷阶段分别计算保持率/反转延迟和即时分类，BPI vs CMQ 并列 |
| 分指归一化在低预紧时放大噪声 | 监测分母下限/信噪比/饱和，跨预紧报告失效范围 |
| sym/anti 受到装配不对称污染 | 双指互换、贴装记录、增益不匹配诊断；不要把数学正交等于物理完全解耦 |
| UMI 动作与机器人动作不同 | 模式 A 的真值用于表征，模式 B 只标示可验证示教量；单独验证动作映射 |
| 不同网络预算造成不公平 | 匹配历史、数据、优化/模型选择预算，分别披露参数、运算量和实测时延 |
| 漂移稳定但闭环无增益 | 接受负结果，定位是任务可观测性、控制权限还是动作接口限制 |
| 只靠夹得更紧获得稳定性 | High-Grip 对照，记录真实握力（如有）与 effort / 损伤 |
| 机械臂/夹爪安全与传感延迟 | 残差限幅、变化率限制、无接触门、过期帧回退、watchdog、急停 |

## 6. 立即可执行的任务清单

- [ ] 明确 UMI/机械臂具体夹爪版本、FlexiTac 具体批次/阵列规格、双指贴装/保护/接线与预算。
- [ ] 搭建 UMI + 触觉 + 相机 + 位姿/宽度 **同一记录程序**，保存不丢失原始时间戳；完成 10–20 trial 的 P0。
- [ ] 准备固定 UMI 的刚性夹具、低载受控施力工具与至少一种**独立真值**通道；核对四向扰动的坐标和载荷方向。
- [ ] 完成 P1 小规模方向可观测性、持续载荷和反转 Pilot；画 raw / BPI / CMQ 分阶段响应图并报告反例。
- [ ] Pilot 后冻结正式试次时长、载荷、预紧和主指标，再执行跨 Session P1 采集。
- [ ] 建立统一特征导出、session-level split、Raw/Scalar/MCF/BPI/CMQ 对照和 sample-efficiency 脚本。
- [ ] 机械臂闭环准备完成后先只跑 Fixed/Scalar/BPI/CMQ；扩展 Raw/High-Grip 与 3-DoF 需明确公平和安全条件。
- [ ] 任何真机性能 claim 必须给出独立试次、原始日志、统计不确定性和负结果。
