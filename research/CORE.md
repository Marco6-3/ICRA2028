# 研究主线：选择性触觉记忆支持执行中的快速修正

状态：待验证研究路线，2026-10-05。

## 问题

视觉慢策略提供任务和几何上下文，执行中的触觉反馈反映接触变化。当前触觉读数未必足以区分“仍在接近卡扣”“已经越过卡扣”“卡死后卸力”等状态；另一方面，历史中也包含已结束的接触、漂移和与当前动作无关的事件。

因此需要研究的不是笼统的“加入触觉是否有用”，而是：

> 在有反应延迟与存储限制的闭环策略中，怎样保留仍影响当前决策的接触历史，并及时遗忘过时信息？

## 现有能力与问题边界

| 依据 | 已有能力 | 本项目需要额外检验的部分 |
| --- | --- | --- |
| T-Rex | 时序触觉编码、快慢专家、执行中触觉修正 | 在同等控制预算下，固定近期窗口与选择性记忆各适合什么接触过程 |
| TacMamba | 流式历史压缩、将压缩状态注入低频 VLA | 历史记忆能否改善独立的执行时动作修正；收益是否超过强 GRU/短窗基线 |
| TacForcing | 执行时更新与 EATA；已有消融支持 | 给临近执行的动作提供何种历史；不是重新声称“执行时更新有用” |
| ImplicitRDP | 因果 GRU 力编码和结构化快慢融合 | GRU 已经足够时新机制是否还有实际价值；共享上下文本身不是新贡献 |

来源详见 [论文地图](../papers/README.md)。这些差距是本项目的研究切入点，不能据有限检索宣称领域空白。

## 一个可检验的核心假设

**H1：当有用接触事件的持续时间和间隔随对象变化时，依据输入选择保留/遗忘的记忆，在相同延迟预算下，比固定短窗更能支持执行时修正。**

竞争解释：

- 收益只来自更多历史、更多参数或更多训练，而不是选择性。
- 记忆只在数事件或识别任务阶段，不是在帮助接触控制。
- 机械柔顺性、简单事件检测或低通滤波已经足够。
- 编码器更快，但传感器/通信/执行延迟决定了系统表现，网络优化没有闭环价值。
- 旧记忆在接触切换后产生误导，因此当前帧或短窗反而更好。

这些解释可以并存。记忆胜过当前帧不等于 Mamba 胜过 GRU，也不等于学会可解释的真实动力学。

## 候选实现与作用位置

令已到达的触觉、关节状态与上一实际执行动作为输入：

```math
h_t = f_\theta(h_{t-1}, T_t, q_t, a_{t-1}^{exec}, \Delta t)
```

慢策略产生任务/视觉上下文 c_k 和动作计划。快策略在执行时读取当前触觉与 h_t，输出局部动作修正或下一待执行块：

```math
a_t = g_\phi(c_k, a_t^{nominal}, T_t, h_t)
```

这是功能接口，不宣称等同于 T-Rex 的 cascaded flow，也不强制采用相加残差。先沿可用基线的动作参数化实现，避免同时更改动作空间、控制器和记忆模块。

首轮固定 q、执行动作和时间信息的可见性，只比较记忆方式。行动条件化若要独立研究，另做消融；不能只给新模型更多传感器输入。

候选从简单到复杂：

- 当前帧；当前帧加因果滤波/变化率。
- 固定短窗；多个窗口长度；指数衰减汇聚。
- 持续更新的 GRU；有限窗口因果 Transformer。
- Mamba 选择性状态；或显式保留关键事件的记忆。

一次只开发一个新增机制。选择性不等于必须 Mamba，指数衰减也未必适合稀疏但重要的早期事件。

## 第一篇论文的范围

主要任务是接触状态歧义与执行时修正，不同时承诺世界模型、通用 VLA、跨本体、事件触发通信和完整动力学辨识。

拟争取的贡献（尚未成立）：

1. 可重复说明哪些接触过程使“当前帧/固定窗”不足，以及何时历史会有害。
2. 一个针对该问题的简洁记忆机制，在强基线和相同端到端预算下有收益。
3. 未见接触条件下的闭环证据与失败边界，说明收益不只来自记住训练轨迹。

“首次把 T-Rex 和 TacMamba 合起来”“Mamba 更先进”“高频一定更好”都不是可接受的核心论证。

## 长期价值

同一内部接触状态后续可以服务短期预测、语义重规划和交互适应，但每次扩展需回答新增能力解决了哪个真实失败。长期主线稳定，第一篇结论由证据决定。
