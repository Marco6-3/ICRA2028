## 1. 两种严格零样本归一化协议说明
为避免跨任务迁移中隐藏统计泄露，所有对比均在以下两套协议下同步评测：
1. **`src_norm`（纯零样本物理尺度）**：冻结编码器**只使用源任务训练集均值/方差**，完全不接触目标任务的任何接触统计量（直接考验真实跨任务零点/量纲漂移）。
2. **`tgt_norm`（目标训练集标准化、零梯度微调）**：输入冻结编码器前仅用目标任务 `train_eps` 统计量做 Z-score（不碰 val/test），编码器权重 100% 冻结。

## 4. 四大论文级核心发现（含透明边界）

1. **双向零样本迁移全面成立，且 `Xfer_PAEC_z16` 甚至可持平/微超目标域内自训**：
   - `wipe → peel`（`src_norm 30%`）：`0.58805` 优于域内 `peel` 自训 `0.59032` 和纯本体 `0.59301`；`tgt_norm 100%` Reversal `0.96816` 持平/微超域内最强 `0.96928`。
   - `peel → wipe`（`src_norm 100%`）：`0.39521`（且 `+1.5σ` 零漂下 `0.39711` 仍优于无力触觉的 `B0 0.40057`！），反超 `wipe` 域内 `PAEC_z16 0.39690`。
   - 同期 `Xfer_B2_MAE` 与 `Xfer_B3_LatentJEPA` 在双向迁移、两套协议、全部预算下**100% 全线劣化下游策略**。
2. **消融证明 `b + g` 分解与 `DriftAug` 在跨任务迁移中缺一不可**：
   - 在 `peel → wipe (tgt_norm 100%)` 中，去掉 `b+g`（`Xfer_B4_NoBG = 0.40297`）或去掉零漂增强（`Xfer_Abl_NoDriftAug = 0.40077`）均直接掉到 `B0_ProprioOnly (0.40057)` 以下，唯有完整的 **`Xfer_PAEC_z16 (0.39557)`** 稳定胜出并拿下 Reversal 第 1（`0.56294`）。
   - 在 `wipe → peel (src_norm 100%)` 中，去掉零漂增强后 `Xfer_Abl_NoDriftAug (0.55461)` 同样直接输给 `B0 (0.55349)`。
3. **清晰的结构性分工——域内用 `z + Probe`，跨任务用纯 `z_16`**：
   - 域内任务中，虚拟探针 `PAEC_Probe` 依赖同域动作-力映射头 $g_\phi$，往往能进一步压低 MSE；
   - **跨任务迁移中，`Xfer_PAEC_z16`（仅用 16D 压缩隐状态）几乎全面优于 `Xfer_PAEC_Probe`**——因为 $g_\phi$ 绑定了源任务的动作空间几何（如 3-DOF vs 6-DOF），而瓶颈隐变量 $z_t \in \mathbb{R}^{16}$ 学到了真正**任务无关的接触动力学表征**。
4. **严格边界声明**：
   - 当源任务缺少目标任务的关键动作自由度（如 `peel` 缺旋转 $\to$ `wipe`）时，前向预测器 $g_\phi$ 本身无法直接零样本预测新自由度的力增量（`dw3_r2 < 0`），仅编码器状态 $z_t$ 实现正向迁移；
   - 以上全部为离线 Action-Chunk BC 评测，距离顶会投稿仍需补齐 **闭环策略成功率**（仿真/真机）与 **带独立外扰/相变真值标签的惊奇度验证**。
