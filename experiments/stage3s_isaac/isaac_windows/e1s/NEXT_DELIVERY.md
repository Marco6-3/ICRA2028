## 时序探针没有支持预设的恢复结论

预指定 W=8 的均值+差分累积相对同划分单帧 MCF，平均方向准确率变化 −1.30 个百分点，成对条件 bootstrap 95% 区间约 [−9.53,+6.28] 个百分点。所有 W=4/8/16 结果均保存，没有选测试最优窗口替代预指定窗口。

旧反向诊断本来已分正负加载时段，因此不能把 50% 直接归因于整段抵消。历史改善或失败均不是 GRU 必要性证明；更不能将失败自动改称“假性失效”。

因果性及差分望远镜和式测试通过；输入没有外力、加载时钟、材料标签或物体真值。全时间序列先构造历史，再用独立加载标签评价。

## E2 四组和交互结果

| 配置 | 总参数 | 条件平均方向准确率（三 seeds） |
|---|---:|---:|
| Scalar + GRU T16 | 49832 | 31.1% |
| Static s_t + MLP | 50015 | 38.6% |
| Static MCF token + MLP | 50192 | 40.4% |
| MCF + GRU T16 | 49512 | 39.6% |
| Dense + GRU T16 | 50093 | 32.9% |
| Dense + GRU T17（历史校正） | 50093 | 35.0% |

MCF T1 为 40.5%；预指定 representation × memory 交互为 +0.07 个百分点，条件 bootstrap 95% 区间约 [−11.19,+11.80] 个百分点，未确认有益交互。保留 s_t-GRU、去 CoP、去面积和 50% 帧预算消融；不以最好 seed 代替平均。

MCF/Scalar token 包含相邻差分：T16 实际涉及 17 个 Raw 时刻，T1 也已含两个时刻。追加 Dense T17 是历史权限审计，不覆盖原结果。GRU token 数与底层 Raw 时间覆盖分别明示。

Static MCF 的 32D token 已有相邻差分，40.4% 是“无学习循环状态”的结果，不能叫“完全没有历史信息”。它与 MCF-GRU T16 的 39.6% 接近，同样没有支持“必须加历史 GRU”的叙事。

不能只看方向准确率：Static s_t / Static MCF 的 Fx/Fy 回归 RMSE 在当前留出域可达到约 95/37 N 与 61/68 N，而载荷只有 0.2 N。这些严重外推失败没有裁剪或删除。MCF T16 的 Fx/Fy RMSE 约 0.169/0.164 N，Dense T17 约 0.194/0.166 N，也尚不足以证明高质量观测器。Static 与 GRU 结构/激活及域外输入归一化差异可能混入回归差异，不能将这种失稳当作记忆机制的证据。

对保存的同一归一化器审计：训练输入标准化后的最大绝对值约 10.5，读出增益留出域约 7931；最小标准差被固定为 1e−6。该放大与域外回归失败一致，但没有证明它解释所有失败。详见 [归一化诊断](outputs/e2_static_control_01/normalization_diagnostics.json)，后续需用开发域和物理尺度设计稳健归一化，不能在当前测试分数上改尺度后抹去原结果。

本 Dense CNN 在训练域方向准确率约 92%，MCF 约 99.6%；所以当前结果既包含泛化差异，也包含表示/架构/优化差异。没有充分证明这个 Dense 是最优强参照，不能据此证明 MCF 数学最小充分。T1 GRU 的初始隐藏状态为零，部分 recurrent 权重不参与 T1 的预测；名义参数匹配不等于活跃计算完全相同。

50% 对照保留全部训练条件，只减少监督窗口，使用同一训练域归一化权限；不是独立 trial 样本复杂度。所有配置使用同样训练末端与独立激励目标；没有将留出的摩擦条件混入训练后仍称未见泛化。测试域属于已检查过的开发 pilot，不是全新盲测。

## 维数不自动转化为软件入口时延优势

Raw→特征/归一化→有限历史模型的 CPU 软件入口，三个模型 seed 的 P95 平均值约为：Scalar T16 0.64 ms、Static s_t 0.21 ms、Static MCF 0.25 ms、MCF T16 0.76 ms、Dense T16 0.66 ms、Dense T17 0.82 ms。MCF T16 的 P50 约 0.70 ms，Dense T17 约 0.64 ms，两者排序会随指标变化，不能宣称普遍时延优势。

Dense 每帧 CNN 编码被缓存；它与完整有限窗口前向数值等价（所有模型误差 <1e−5）。没有把 Dense 重复编码全部历史的冗余实现当成必然成本。也没有把仅网络输入后的 0.09 ms 数字冒充完整入口成本。

这些只是在本机、CPU 两线程下的已有 Raw 到输出的软件测量，未包含传感器读取/传输、物理更新、执行器，也未测能量。120 Hz 是仿真物理步长规格，不等于整条 CPU 物理管线实时 120 Hz。

## 物理初始化与支撑去混淆

初始支撑移除对照暴露了获取夹持的顺序问题：开环初态在无桌面时掉出目标夹持区域，反馈无法在 120 步/0.004 rad 预算内重新捕获。所有拒绝记录保留。SDF 代理反馈在有桌面时也可能已有接触，却无法达到 proxy=8 的设定值而在闭合上限处拒绝，这不是“完全没接触”。

随后按预先定义的零扰动矩阵检查九种初始放置/闭合条件：五种条件两次均满足目标两指接触≥95%、环境法向接触<0.0001 N、相对位移≤5 mm。按最低高度偏置、最小可行闭合量选 initial02（Z=0 mm、额外初始闭合 0.003 rad），再运行固定 0.2 N 正负偏心加载。

这 18 个加载试次的目标 table/地面/另一物体法向接触通道均为零，证明本轮确实移除了这些支撑通道。8/18 满足所列接触/位移工程标准；这是固定夹持的开发检查，不是 MCF Reflex 的闭环成功率。零扰动相对位移约 4.7 μm；同一基准夹持下 +Fx/−Fx 扰动可出现约 22.5/8.9 mm 相对移动，表明任务并非所有方向都同样稳定。进一步放松初态的失败全部保留。

当前门限针对目标对应两指；四指分别观察两件物体。不能要求单件目标同时接触四指，也不能把 SDF proxy 门限等同于真实握力保证。旧字段 `sensor_net_contact_force_world_n` 实际为 PhysX 接触法向通道，不含完整摩擦力；本轮审计和解释采用这一限定。

运行时展开桌面碰撞实例曾使 PhysX 视图失效，失败保存在 contact_01。正确版本在视图初始化前完成实例/碰撞设置。旧运行使用的代码快照与失败日志保留；原作者物理/触觉源文件未改。

## 下一步与当前未完成事项

下一批训练数据应来自已核验的无支撑场景，增加独立初态、加载范围、几何与训练域随机化；测试摩擦/读出条件须与训练范围分开。读出增益随机化仍不是材料刚度随机化。

E3 专家控制器和学生残差策略尚未训练。现有模型输出外部激励重构/方向，不能直接部署成 Δg。下一步先用固定名义夹持、固定 High-Grip 与特权状态专家检查仅 Δg 的可恢复域，再在同一教师数据上训练 Scalar/MCF 学生，保留 effort、饱和和相对滑移/倾角。手腕顺应不属于当前 Δg 权限。

真机 FlexiTac E1 未执行；一组单调 CoP 曲线只能支持所测条件，不能彻底确立所有加载/材料条件的 H-Obs。不得把仿真 SDF 的成功或失败推广为真实软层结论。
