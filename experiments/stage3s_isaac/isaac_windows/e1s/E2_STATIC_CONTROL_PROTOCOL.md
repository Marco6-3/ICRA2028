# Static MCF 8D/指的完整输入对照

2026-10-13，运行前版本 1。主开发实验 B 使用 s_t 单帧 4D/指空间状态，仍保留作为无差分的静态消融。补充冻结范围中的 Static MCF 无时序骨干对照：当前 MCF token `[s_t,Δs_t]`，四指 32D，双层 MLP，不用 GRU 历史。

由于 Δs_t 的存在，它含两时刻 Raw 信息；“无记忆”只指无学习的循环状态，不是完全无历史观测。与 MCF-GRU T1 在底层 Raw 时间权限上相同，与 MCF-GRU T16 比较当前 token vs16 个 token。

总参数仍最接近 50000，整数隐藏宽度只依据参数计数选择。8 训练/36 未见条件、seeds=7/11/19、80 epochs、lr=0.001、batch64、双任务损失与评价末端均不变。没有按已看到的分数改超参数。三个固定 seed 全部保存，不覆盖已有 Static s_t 或 GRU 结果。
