# 流式 Reflex 改进协议

第一版学生在八个测试条件中七个达到 2 mm；0.20 N +Fx 为 2.208 mm。保留第一版全部测试，作为原型改进依据，测试数据不进入下一版训练。

第二版保留同一个 GRU64×2、同一动作范围和专家，仅将滚动 16 帧、每次清零 hidden 改为每个 trial 保留 GRU hidden；训练整条 180 帧序列，每条 trial 开始清零。增加独立学生运行开发集：名义摩擦/读出增益，0.16/0.20 N 四方向 step，加零载荷，onset=0.25 s。在学生实际状态上保存同一特权专家标签，并与原专家训练集共用；原来的四个 ramp 验证条件仍独立保留。

固定 240 epochs、三 seeds 7/11/19、Adam 0.001、梯度上限 1。按验证条件平均 MSE 选择 epoch 和 seed。MCF 和 Scalar 使用同样的合并数据，网络仍不读时钟、载荷或物体状态。

新评估矩阵：0.18/0.20 N 四方向、15 mm 偏心、onset=0.45 s、duration=0.25 s，共 8 条、各 1.5 s。对 Nominal/High-Grip/MCF/Scalar 重新进行成对测试；图固定 0.20 N +Fx，并报告全部条件及第一版结果。新矩阵在本版训练之前冻结。
