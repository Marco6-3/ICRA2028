# Raw 历史权限校正对照

2026-10-13，运行前版本 1。原 33 次开发训练结果保留，不修改其预测或数据划分。

核查发现：MCF 和 Scalar 的每个 token 包含相邻帧差分，因此 T=16 的 16 个 token 实际涉及 17 个 Raw 时刻；T=1 也已涉及两个时刻。原 Dense T16 只含 16 个 Raw 时刻。因此不能把原比较称作所有表示都具有完全一致的底层 Raw 时间覆盖，也不能把 MCF T1 称为完全无历史。

追加 Dense T17 三个 seed 对照，使用与原 Dense T16 完全相同 CNN/GRU 结构、参数、80 epochs、lr、批量和种子，仅多提供一个因果 Raw 历史帧。末端评价位置、监督目标、8/36 条件划分和归一化权限保持相同。匹配底层 Raw lookback，GRU token 数则为 17 vs16，须分别报告。无窗口选择或测试调参。

本追加对照只是修正历史权限审计，不消除物体/会话单一、Dense 优化未充分等开发限制；仍不能作最小充分性或真实闭环结论。
