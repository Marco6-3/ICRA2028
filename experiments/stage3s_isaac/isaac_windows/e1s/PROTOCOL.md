# ICRA2028 E1-S 开发交接与完整 E1/E2/E3 实验协议

日期：2026-10-13。依据 2026-10-10 研究范围冻结稿，保留已有 Stage 1/2P 的正负结果。本目录仅新增仿真扰动、采集和开发 pilot，不覆盖冻结报告或推送 GitHub。

## 科学问题与推进顺序

E1 检验：给定材料、几何、预载及加载条件，正负切向扰动和偏心力矩是否造成可重复、可区分的法向空间重分布。E2 检验：空间表征与历史记忆是否有交互，MCF 是否在合理预算下保留有用信息。E3 检验：MCF + GRU 是否改善偏心扰动恢复，并兼顾 effort、饱和和端到端延迟。

执行顺序 E1-S 仿真设计与加载核验 → 真实 FlexiTac E1 标定 → E2 → E3 仿真控制开发及真机验证。研究范围固定，物理机制、超参数与结果由实验决定。不能因为 pilot 不支持某个机制就缩小 E2/E3 主比较，也不能把仿真成功当成真机结论。

## E1-S 物理链路与数据权限

保留 ALOHA、原 URDF、物体及 WarpSdfTactileSensor。每个物理步先施加外部 wrench，物理引擎更新物体与接触几何，再读触觉；不写入载荷对应的 CoP 或压力图。

载荷可在世界、随物体转动的局部、独立冻结参考坐标系中定义。参考系支持从指定指尖保持姿态下的网格平面取得两条切向轴，第三轴为叉积法向；它只确定加载坐标，不规定压力响应符号。载荷作用位置是相对物体 COM 的米制偏置，同一坐标系下计算 `M_COM = r × F + τ`。向 PhysX 当前 COM 提交等效外力及力矩。偏心点是加载器的虚拟力臂，正式物理夹具的作用点需另外确认。

每试次保存：

- 四指 Raw `[T,4,12,32]`、Scalar `[T,4,2]`、静态状态 `[T,4,4]`、逐指 MCF `[T,4,8]`。Scalar 为 `[fN,ΔfN]`；四指拼接为 8D Scalar / 32D MCF，不能宣称整个输入只有 8D。
- 原响应为归一化 SDF 穿透 proxy；`fN` 是响应和，CoP 是网格归一化坐标，A 是有效单元比例。阈值 pilot 暂定为 0，正式阈值须用开发标定噪声确定。
- 外部激励力 N、COM 力矩 Nm、作用点、当前 COM、施加前位姿、等效局部 wrench；这些由加载协议和独立物体状态决定，不由 MCF 推导。它们不包含重力与接触反力，不能称完整接触 F/T。
- PhysX 逐指净接触合力与其网格法向投影诊断，作为独立于 SDF 响应的仿真接触读出；并非真实六轴传感器标定。
- 物体完整位姿/速度、机器人逐 link 位姿与关节状态、逐指网格世界坐标及支撑 link 位姿。位移和姿态变化由引擎状态计算；滑移需转换到夹爪参考系，不能用世界位移代替。
- 物理步起止时间、全局步号、host 计时、trial ID、条件、来源提交与文件 SHA-256。每个物理步采一次，120 Hz；暂未接入控制器，host 时间不代表真机 sensor→actuator 时延。

差分在连续相邻帧上计算。每次恢复状态后重新预填流状态，再录制首帧；不能先筛活跃帧再拼历史。每试次独立写 NPZ/JSON，失败保留 manifest 和日志，现有输出目录禁止覆盖。

## 开发 pilot 矩阵、预算与停止规则

先做少量 smoke，校验载荷确实通过引擎改变物体状态。无接触校验对比零载荷与正负世界 Fx/Fy 的 `mΔv/Δt`，检查四个方向与单位；偏心 wrench 用引擎角动量变化检查矩方向和数值。校验容差是工程检查：力绝对误差 <0.01 N，力矩 <0.00015 Nm。超限即停止，不把错误激励用于科学判定。

默认 pilot 为 45 条稀疏条件 × 3 次恢复状态重复，共 135 试次，每次 90 步、0.75 s；最多 12150 个记录物理步，另外记录初始化和校验预算。基准载荷 0.2 N，t=0.25 s 开始，0.25 s 后释放，峰值虚拟力臂 ±15 mm。它们是开发设置，不是冻结的正式范围。

| 因素 | pilot 覆盖 | 正式 E1 必须保留 |
|---|---|---|
| 方向 | ±Fx、±Fy，两条冻结切向轴；零扰动 | 四方向，反向留出与未见载荷 |
| 作用点 | COM、负/正法向偏置的虚拟力臂 | 中心/左右及其他可实现偏心，记录夹具坐标 |
| 曲线 | 阶跃、线性渐变、受载区间中点反向，最终释放 | 速度、幅度与迟滞/反向标定 |
| 预载 | 正负 0.001 rad 夹爪目标改变量 | 独立法向载荷控制/分层，不能以指令代替预载真值 |
| 摩擦 | 目标物体原 material 静/动摩擦 ×0.5、×1.5 | 材料配对、接触面摩擦与合成规则核验 |
| SDF 增益 | 读出 stiffness ×0.5、×1.5 | 真实柔性层刚度、厚度及其耦合，不能用 SDF 增益替代 |
| 几何 | 保留原 plug/socket；接口支持独立 plug scale 与 normal offset | 不同物体/接触几何与真实层厚；未跑几何 sweep 不称覆盖 |
| 支撑 | 原装配场景、桌面及另一物体均保留 | 明确加载/支撑边界，必要时设计隔离的受控夹持场景 |

单因素变更避免全部笛卡尔积；没有经过 pilot 选择最优模型。发生非有限值、形状错误、加载校验失败、应用退出或越关节限制即停止并保存失败。幅度不足、触觉不可分或接触丢失保留为结果；不因准确率不足调整到有利条件。若需要下一轮幅度搜索，提前保存新矩阵与理由，前一轮保留。

诊断固定为训练重复 0/1、测试重复 2，标准化只用训练 trial，最近类别中心分类器，不调参。每 trial 使用受载区间均值减受载前均值；时序曲线、逐指结果、方向混淆、零载荷漂移与失败案例全部保存。Raw 按每指总响应归一化以检查空间分布；同时保留 Scalar、静态状态及 MCF 诊断。试次 bootstrap 使用固定 seed=20261013、2000 次，仅作为开发不确定性描述；同一仿真会话中的确定性重复不构成真机独立重复。正式效应量、样本量、检验和成功标准在 pilot 后写单独版本冻结。

正式 E1 按独立 trial/session 分组，留出反向及未见加载/接触条件，比较总强度匹配与空间归一化后是否仍可区分。真实标定报告坐标、漂移、迟滞、SNR、独立 F/T、姿态与相对滑移关系、置信区间及失败域。仿真与真实不同的结果分别保存。

## E2 四组主比较与消融

| 组 | 表征与记忆 | 作用 |
|---|---|---|
| A | Scalar + GRU | 标量历史基线 |
| B | Static MCF，无记忆 | 单帧空间信息 |
| C | MCF 8D/指 + GRU | 主候选 |
| D | Dense Raw + CNN/MLP + matched GRU | 高维强参照 |

保持共同 trial、样本、目标、训练/验证/测试边界及调参预算。全指或逐指策略须明示，不能混称输入维度。两层 GRU64 仅为当前预算下第一版，训练数据不得使用测试真值。特权教师状态与学生可用信息分离。

保留 `s_t` / `[s_t,Δs_t]`、有无 CoP、面积、T=1 / 更长历史。当前 `[Fx,Fy,Mx,My]` 重构、正负方向混淆、跨载荷/材料/几何泛化、表征编码成本与时序模型延迟分别报告。按 trial/session 进行 paired representation × memory 交互检验，不能把更多窗口当作更多独立样本。冻结训练 seeds、预算、主要效应与 bootstrap 单元；MCF 最小充分、差分必要性、GRU 最优或 Mamba 物理不适用均未成立。

## E3 偏心闭环控制

主比较 Fixed/Nominal、Scalar Reflex、MCF Reflex；保留 Fixed High-Grip 检查 effort 替代解释，在主结果可信后加入 Dense Reflex。Privileged Oracle 为辅助参考，不自动视为理论上界。共同名义动作、扰动、频率、观测权限、动作限制、数据与测试 trial，首轮动作仅 `u_nominal + Δg`。

Stage 2P 的力/力矩重构 checkpoint 不能直接当作残差控制器。先在仿真开发集构造使用真实状态的专家，验证 Δg 权限下可恢复条件，再用相同专家数据训练 Scalar/MCF 学生；训练可用特权监督，正式测试只用各自触觉和公平共享机器人状态。不可恢复条件记录为动作空间边界，不等同于 MCF 无价值。

指标包括最大倾角、夹爪相对滑移、恢复时间、掉落率、峰值/积分 effort、饱和、损伤代理与实测端到端延迟。握力替代、异步观测、ZOH、延时/旧帧、无接触门控、watchdog 和安全限幅须明示。真实 FlexiTac E1 标定和硬件安全 bring-up 后再验证真机闭环；仿真控制收益不推广为真实结论。

## 本轮验收

1. 世界/物体/独立参考坐标加载功能与正负力、偏心矩动态校验。
2. 四指 Raw、逐指状态与 MCF，连续差分、无特权泄漏的字段分离。
3. 外部激励、独立物体状态、接触读出及同步时间保存。
4. 固定条件重复，加载一致性与响应重复差异明确报告。
5. 正负方向混淆、误差、零扰动漂移与全部失败案例输出。

上述为工程开发验收。完成也不等于 H-Obs、E2、E3 或论文结论通过。几何/可变真实柔性材料实验、正式跨会话划分和真机标定均单列待验证。
