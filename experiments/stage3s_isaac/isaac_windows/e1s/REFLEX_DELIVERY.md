# 归一化修复与仿真闭环 Reflex 交付

已完成两项实际开发：修复数千倍归一化放大，跑通触觉 GRU→单一抓握增量 Δg 的 Isaac Sim 闭环。0.18 N、15 mm 偏心、四方向测试全部达到滑移 ≤2 mm，同时减少持续握持。

## 已取得的结果

### 归一化修复

使用训练集 median/IQR、通道量纲尺度下限与 [-8,8] 饱和截断。回归输出不截断；因此改善并非直接裁掉预测误差。

- 原 pilot 中 7931 倍的输入放大路径被有界处理消除；原 Static MCF 的 Fx/Fy RMSE 60.91/68.25 N，修复后同划分为 1.00/1.34 N。
- pure_loading_01 不重跑物理仿真，按完整条件重新验证：Static MCF 方向准确率 48.1%→57.2%，Fx/Fy RMSE 0.147/0.273→0.133/0.189 N。
- 完成两套数据的 33 次训练。MCF-GRU 和其他表征的方向准确率没有一致上升，全部结果保留，数值稳定性与预测精度分别评估。

### 实际闭环成果

右侧目标两指初始闭合 0.003 rad，Δg∈[0,0.003] rad，仅调整抓握，不移动手腕。四指逐指 8D MCF 拼接为 32D，GRU64×2，43,841 参数。

流式版本测试：两种幅度 0.18/0.20 N ×四方向，15 mm 偏心，step onset=0.45 s，持续 0.25 s，每条记录 1.5 s。

| 0.18 N 四方向 | 结果 |
|---|---:|
| MCF Reflex 达到滑移 ≤2 mm | 4/4 |
| MCF 最坏相对指尖滑移 | 1.013 mm |
| +Fx Nominal→MCF 滑移 | 15.728→1.013 mm |
| 相对 High-Grip 的平均法向力积分降低 | 33.9% |
| 相对 High-Grip 的扰动后平均法向力降低 | 37.7% |

八个测试条件总体：MCF 7/8 达到 2 mm；平均法向力积分降低 33.7%，扰动后法向力降低 37.5%。尚未达到的 0.20 N +Fx 为 2.823 mm，单独保留其预先指定曲线。High-Grip 8/8 达标且全程使用最大增量；流式 MCF 没有达到动作饱和门限的帧。各组均无掉落、无桌面/地面/另一物体支撑接触。

Scalar 流式参照同样为 7/8，最坏滑移 2.060 mm，平均法向力积分 5.448 N·s；MCF 为 5.046 N·s。两者呈现滑移与握持成本权衡，当前闭环成果支持触觉反馈的实用性，表征优势继续由完整 E2 比较回答。

MCF 控制调用 P95 最大值 0.574 ms。它包含调试专家标签计算，是 CPU 软件调用时间；物理步骤以逻辑 120 Hz 执行，未声称整套系统达到真实实时 120 Hz。

## 训练与版本

- 专家来自已实现物体位姿的平面速度和角速度，输出阻尼抓握补偿，按 0.25 s 衰减。直接读引擎速度的第一版专家有接触稳定化速度干扰，原记录和对应源码保留。
- 专家数据 25 条，其中 21 条训练、4 条 ramp 条件验证；摩擦与 SDF 读出增益使用 0.8/1.0/1.2 交错条件。
- 第一版用长度 16 的滚动窗口，三 seeds，实际闭环 7/8 达标，最坏 2.208 mm、法向力积分降低 12.9%。
- 第二版追加 9 条独立学生运行的开发轨迹，在实际学生状态保存同一专家标签；合计 30 条训练、4 条原验证，完整序列训练并在每条 trial 中保持 GRU hidden。原第一版测试数据没有参与训练。
- MCF 与 Scalar 共享数据，各三 seeds；epoch 和 seed 只按开发验证误差选择。流式模型测试前冻结矩阵，未按最终测试选模型。
- 改进组合未做流式/数据聚合的独立消融，不能将两版成本变化单独归因于其中一项。
