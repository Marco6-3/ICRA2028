# E1-S pilot 数据核验与方向诊断

采集 18 个试次、1620 个物理步。核验状态：`validated`。

每指 Raw 为 12×32，MCF 为 8D；四指联合诊断分别为 1536D 和 32D。

本次是开发 pilot。重复 0/1 用于拟合均值与标准化，重复 2 用于诊断；没有按帧随机划分。重复来自同一仿真会话与状态恢复，不能视作真实独立实验。

## 加载与记录核验

力的无接触动态校验最大误差 1.19209e-08 N；偏心力矩校验最大误差 9.82733e-06 Nm。

外力/力矩为施加到 PhysX 的已知激励，独立于触觉特征；并非从法向阵列反推出的真值。接触合力另外记录自 PhysX 接触传感器，不能把它与外部激励或完整六轴 F/T 等同。

analysis.json 另外保存每指支撑 link 坐标中的物体相对位置和朝向变化，基准为录制首帧。它是独立引擎运动学读出，不是接触界面的微滑移真值。

因果 MCF 重算最大误差 0；同步时间、形状、有限值与逐文件 SHA-256 的核验结果见 analysis.json。

## 重复性与失败边界

同条件最大加载差：0 N / 0 Nm。
恢复状态后的最大物体位置差 0 m；Raw 重复 RMSE 最大值 0。接触求解器 warm-start 缓存未序列化，因此不保证逐位一致。
本次恢复重复在保存精度下完全一致，诊断测试集包含训练轨迹的精确重复。这核验工程可重放性，但方向准确率和 bootstrap 区间不能用作独立泛化、统计显著优势或真实重复性证据。

共保存 0 条逐表示误判记录，包含左右非目标指尖的结果；没有删去弱响应或接触变化试次。

本组保留原作者机器人/物体几何，固定底座并禁用 table 碰撞、下移接物地面。环境接触是否为零及夹持失败见 CONTACT_REPORT.md。该干预不模拟柔性层刚度或迟滞。
