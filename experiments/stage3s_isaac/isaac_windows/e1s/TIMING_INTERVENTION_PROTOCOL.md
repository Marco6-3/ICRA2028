# 抓握时刻干预（2026-10-14）

前两组诊断显示：纯力/纯力矩均存在早期弱信号；闭合阶跃的法向力10–90%均落在首个采样帧。为进一步检验“补偿来得晚”而不混同驱动器本体带宽，固定加载F=0.20 N、e=15 mm、+Fx，直接改变同一最大抓握补偿开始时刻。

延时相对载荷开始设{-100,0,8.333,25,50,100} ms，每条件两次状态恢复。Δg=0.003 rad，自指定时刻保持至载荷释放，再以0.25 s时间常数衰减；初态、动作上限、载荷与测量不变。12条、2160帧，不重新训练学生。

这个控制器明确使用加载时钟，是特权时序干预，不称触觉策略，也不与学生公平信息预算混淆。它只回答改变握持时刻能否改变这条载荷的结果。所有时间点和失败保留，不能据一个成功时刻反推纯触觉必然能提前检出。
