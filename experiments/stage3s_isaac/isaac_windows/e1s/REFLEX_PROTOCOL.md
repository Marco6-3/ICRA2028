# 归一化修复与仿真 Reflex 原型

本轮直接实现离线修复和闭环原型，目标是 0.2 N、15 mm 偏心载荷下滑移不超过 2 mm，并较固定高握持降低持续法向力。真实 E1 标定等待硬件齐备。

## 离线修复

pure_loading_01 按唯一条件划分：名义预紧的四方向训练，额外松开 0.001 rad 的四方向测试，精确重复不进入训练或测试。使用相同模型、80 epochs、seeds 7/11/19 比较原 Z-score 与训练集 median/IQR、量纲尺度下限、[-8,8] 截断。回归输出不截断，以独立检验输入修复；报告 Fx/Fy RMSE、方向准确率和归一化最大值。旧 NPZ 与报告保持可核验。

## 闭环开发

沿用悬空初始化：固定机器人底座、关闭桌面碰撞、接物地面降低，右侧目标两指初始闭合 0.003 rad。输出仅为两关节反向同幅的抓握增量，Δg∈[0,0.003] rad，最大总闭合 0.006 rad。没有手腕动作。

先在四方向 0.2 N、15 mm 偏心的开发载荷上比较 Nominal、固定最大握持、特权运动状态专家。专家只读上一帧物体速度、姿态变化，用运动阻尼与带衰减的抓握补偿，不读未来载荷。确认动作范围可恢复后采集专家数据。若需要修改专家或动作上限，保留对应开发记录及版本。

学生使用四指逐指 8D MCF（共 32D）及长度 16 的因果历史，双层 GRU64→单输出 Δg。同一专家数据亦训练 Scalar 学生作为参照；专家标签可读特权状态，学生推理仅可读触觉。初始化和模型归一化参数一同保存。使用固定三 seed，通过开发验证选择模型；冻结评估载荷后不根据测试曲线改模型。

开发记录：第一版直接读取引擎速度，受接触稳定化速度影响变成常高握持；该记录保留为 reflex_dev_oracle_01。第二版用相邻已实现物体位姿计算参考平面内速度及角速度，增量 = clip(0.75·max(v−0.00015,0)+0.003·max(ω−0.01,0),0,0.003)，补偿记忆按 0.25 s 时间常数衰减。开发 +Fx 相对滑移 1.981 mm，因此固定第二版进入学生训练。此后学生训练不使用引擎速度，也不向网络提供独立物体状态。

训练矩阵为四方向×0.12/0.20/0.28 N×step/ramp 加零载荷，摩擦和 SDF 读出增益交错为 0.8/1.0/1.2；其中 0.20 N ramp 四个完整条件用于验证，其余用于训练。固定 160 epochs，seeds 7/11/19；每 10 epochs 在验证条件记录误差，按验证平均 MSE 选择 epoch 和 seed。最终测试四方向×0.16/0.20 N，载荷开始时刻变为 0.35 s、持续 0.25 s，每条记录 1.5 s。矩阵在训练前生成冻结，第一张曲线固定为 test_01_0（0.20 N +Fx），全部方向一并报告。

最终比较 Nominal、High-Grip、MCF Reflex、Scalar Reflex，另保留专家参照。以独立位姿计算物体相对于两指支撑 link 的位移，报告最大滑移、最大姿态偏转、法向接触力积分及峰值、Δg 饱和比例、加载结束后的握持回落、环境接触、掉落和软件控制时延。法向力为 PhysX 正常接触投影，SDF fN 不标为牛顿。开发目标不写成预先通过的结果。
