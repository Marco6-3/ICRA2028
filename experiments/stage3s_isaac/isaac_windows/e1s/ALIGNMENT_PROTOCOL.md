# A/B/C 开发对照：等预紧力、成本—安全图与早期触发

2026-10-14。原相图、模型和原始记录不变。本轮是开发仿真干预；不把用户预期写成结论。

## A：消除扰动前握力差异

- 固定原夹持快照、接触材料、四指观测、120 Hz 和原加载坐标系。
- 实测右侧两指法向接触力投影之和，以物理 N 校准到 3.06 / 4.42 N；SDF 响应和不作为 N。
- 相同初始化循环：每步按误差调整闭合位置，增量上限 0.1 mrad，比例 0.7 mrad/N，最多 240 步；两指接触门限同原协议，误差 ≤0.01 N 连续 12 步才接受。失败即停止，不丢弃困难试次后宣称完成。
- 静息期固定校准后位置。学生每步更新其 GRU 历史，t<0.45 s 禁止残差动作；0.45 s 统一释放，残差为当前预测减去最后静息帧预测。这里只使用共同加载时钟作 A 的实验干预，不能称作自主触觉触发。
- 允许残差为负；总闭合权限始终为原名义指令外额外 [0,3] mrad。高预紧组剩余增加权限更小，两者绝对执行器权限相同。
- 冻结学生及归一化参数，不重训；静息残差扣除是本轮的新部署方式。
- 完整矩阵：±Fx/±Fy × F={0.10,0.125,0.15,0.175,0.20,0.225,0.25} N × e={0,5,10,15,20} mm，零加载与 ±Fx/0.20 N/e15 mm 的一次复现实验，共 143 试次/组。
- 3.06 和 4.42 N 各比较 Fixed、Scalar、MCF。另运行 5.07 N Fixed。7 组，共 1001 试次。
- 主检验：同预紧水平 140 个单次格点的 MCF−Scalar 安全格差、±Fx 分方向差和共同安全格握力积分；报告重复锚点、实际静息力、绝对饱和比例、环境接触、掉落、最大滑移与倾角。
- 安全仍为全程最大相对位移 ≤2.0 mm、无掉落、环境接触 ≤1e-4 N、初态接触门限通过。1/3 mm 为附加灵敏度分析。140 个格点不是独立随机重复，不给虚假的总体置信区间。

## B：测量成本—安全关系

- 原四组数据保留：Nominal、High-Grip 是固定指令；Scalar 与 MCF 都是触觉反馈策略。
- 两个主图横轴分别为实测静息 N 和同一 140 格点全程平均 ∫FNdt，纵轴安全率；明确原条件与校准后条件是两批实验。
- A 的三种实测静态预紧水平构成新静态参照，不把 Scalar 并入静态基线。
- 只标注样本中非支配点；不预先宣称 MCF 优势，也不把点间连线解释为已测连续安全边界。
- 同时报告配对共同安全格成本与完整格点成本，避免失败试次的低代价误导。

## C：独立弱信号触发干预

- 新开发矩阵 ±Fx × F={0.18,0.20,0.225,0.25} N × e={10,15,20} mm；加载起点改为 0.55 s，静息释放仍为 0.45 s。24 格点 + 零加载 + 两个重复锚点，共 27 试次/组。
- 两种预紧力，均使用同一个冻结 MCF 学生与 A 的基线扣除方式。三个配对条件：无触发、单帧触发短脉冲、三帧确认触发锁存。共 162 试次。
- 阈值仅来自本试次加载前 t∈[0.20,0.45) 的右指 CoP：各指二维中心取中位数，坐标噪声尺度为 1.4826 MAD，向量门限为 max(1e-6,6×尺度范数)。输入严格为上一步触觉；触发判断不使用力、滑移真值或加载起点。
- 脉冲：首次越阈值后拉到相同绝对最大闭合位置，保持 25 ms；锁存：连续 3 帧越阈后拉到相同上限，保持 250 ms 后按 τ=150 ms 衰减。每试次最多触发一次。所有参数现在冻结，不根据测试格点调优。
- 记录零载误触发、实际命令触发时刻、相对于已知加载时刻的事后延迟、2 mm 达标数、峰值 N、积分、饱和时间与释放尾部力。
- 单帧脉冲与三帧锁存同时改变确认和保持机制，是两个工程干预，不把差异单独归因于保持时长。

## 预算与验证

- 9 个 bring-up smoke 试次仅检验校准与接口；正式固定预算 1163 试次，每试次 180 个物理步，共 209340 个记录步。一次确定性夹持快照，不等于泛化验证。
- 校验完整 manifest、SHA256、四指 Raw/MCF 形状、物理力加载校验、时间因果性、静息动作封锁、绝对闭合限幅、同预紧组初态和命令、零载触发、原冻结文件及模型哈希。
- 校准和数值接口故障可修复并另存 smoke；修复需要新版本冻结，禁止选择性删除正式负结果。
