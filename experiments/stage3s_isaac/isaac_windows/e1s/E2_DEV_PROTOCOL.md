# 仿真离线 E2 开发比较：预指定方案

2026-10-13，版本 1。本轮真机设备未齐备，只推进仿真与离线验证。该实验用于开发可复现模型比较，不替代真实 E1 或正式 E2 验证。

## 数据与权限

复用 45 条件的原 pilot，仅使用重复 0。训练 8 个中心/负偏心基准阶跃条件，测试 36 个未见偏心、曲线、预载、摩擦和 SDF 增益条件。该划分与 `TEMPORAL_PROTOCOL.md` 相同。训练全部选中的连续窗口，非零加载帧作为当前目标，不删帧后拼历史。所有方法共用至少 16 帧历史已具备的末端位置；T=1 模型也在同一末端比较。

网络输入仅允许各自触觉。主任务为当前独立外部激励 `[Fx,Fy,Mx,My]`（COM 参考矩、冻结加载坐标），辅任务为四方向分类；不是接触总 wrench 或真实 ATI 标签。两项共同训练，回归用训练目标标准差归一化。目标、加载时序、物体位姿、材料标签及 ID 均不进入输入。

## 架构、预算与比较

主四组：A Scalar + 两层 GRU；B 单帧 `s_t` 空间状态 + MLP（无时序骨干）；C MCF + 两层 GRU；D 四通道 Raw + CNN 编码 + 两层 GRU。四指维数明确为 Scalar 8、s_t 16、MCF 32、Raw 1536；不是整个模型 8D。

固定总参数目标 50000（包括 Dense 编码与双任务 head），通过运行前参数计数选择最接近的整数隐藏宽度。各 GRU 均两层、相同窗口和优化预算；宽度可能不同以匹配总参数，报告实际宽度/参数数，不能声称内部维度完全相同。

完整开发配置：Scalar T1/T16、MCF T1/T16、Static s_t、Dense T16；另跑 s_t-GRU T16、去 CoP 的 MCF-GRU、去面积 MCF-GRU；以及 MCF/Dense 的 50% 训练帧预算。50% 选择在每个训练条件内均匀覆盖加载时段，保留全部条件，属于固定条件下帧预算学习曲线，不能称作独立 trial 样本复杂度。

每配置 seeds=7/11/19，CPU float32、2 计算线程；Adam lr=0.001、weight_decay=0.0001、80 epochs、batch64、gradient clip=1；回归均方误差 + 分类交叉熵等权。无测试选择 epoch、无早停、无测试调参。共 33 次训练，失败保存并报告，不选择最好 seed。不得因为结果不理想更换预算或划分。

## 评价与解释

报告各 seed/条件的方向混淆、Fx/Fy/Mx/My 误差，按条件等权。主要 representation × memory 交互为 `(MCF_T16−Scalar_T16)−(MCF_T1−Scalar_T1)` 的分类准确率差；先对同条件的三个 seed 取平均，再以条件为 bootstrap 单元，2000 次、seed=20261013。训练 seeds 不是额外真实 trial。

保存模型、每帧预测、数据划分和哈希。延迟单独测 batch1：表示编码/网络计算与原 Raw→Scalar/MCF 特征提取分开，均为 CPU 软件计算，不叫物理闭环时延或能耗。Dense 编码计入参数和推理，CNN 的原始输入转换也计入对应软件入口。

不会预设 MCF 达到 Raw 90% 或最小充分性；维数减少、任务非劣与数学最小充分是不同命题。本数据未覆盖独立物体/会话/真实柔性材料，因此即使出现增益，结论只限本开发测试域。

本轮暂不混入域随机化效果：训练摩擦覆盖是单独实验因素，不能通过在已留出的测试摩擦上训练后仍把同一数值叫未见泛化。SDF 增益只代表读出变化。准备采更多独立仿真条件后，再冻结随机化训练集与不重叠测试材料范围。
