# ICRA2028 · 触觉记忆驱动的多速率机器人操作

更新：2026-10-05。状态：研究路线与文献准备；尚未运行本路线的实验。

## 一条长期主线

**研究机器人应当记住哪些接触历史，以及如何用这些记忆及时修正正在执行的动作。**

长期方向：接触状态感知的选择性触觉记忆（contact-aware selective tactile memory）与多速率闭环操作。第一篇论文聚焦：

> 在同等观测、训练与反应延迟预算下，选择性保留接触历史，能否比当前触觉或固定历史窗口更有效地支持执行中的动作修正，并泛化到未见接触条件？

T-Rex 提供快慢策略与执行时修正的参照；TacMamba 提供流式历史压缩的参照；TacForcing 提供触觉与执行时刻对齐的参照。研究以其中一篇最合适的论文为方法母体，沿其公开实现、任务和评价做有针对性的改进，其余论文提供设计依据与相关工作比较。具体网络组件由改进需要决定。

## 现在先做什么

1. 精读 T-Rex、TacMamba、TacForcing 的方法与消融，选定一篇作为主要方法基线，记录已有能力与可改进的具体假设。
2. 优先评估 TacForcing 的执行时触觉条件化作为切入点；若实现、数据或平台不适用，再评估 T-Rex 的快慢专家接口。选定前核查代码与权重可用性。
3. 在所选论文的公开实现与原任务上建立可比较结果，针对历史信息的使用方式做一个明确的方法改进。
4. 先验证“原方法 → 改进方法”的效果与关键消融，再按论文主张补充相关工作比较、泛化与真机证据。

**不把从零比较一组基础网络设为研究起点。** 实验服务于已有论文上的方法改进，具体比较模型在基线和假设确定后选择。
